# LANTERN 官方试题与备考资料集合

核验日期：2026-09-08。共22个官方资源条目：14个样题/样题索引、6个备考资料条目、2个官方公开实际考题视频集合。**这不是22套试卷，也没有下载、复制或打包任何题目正文、PDF、图片、录音或视频。**同一官方样题可能出现在多个地区入口或手册，资源数量不能当作独立题目数量。

## 能否免费下载官方真题？

**可以免费学习官方公开的实际考题选题视频；本轮没有核实到完整历届实际考试卷的官方免费PDF下载。**这里的“没有核实到”限定于本次检查的ETS、IIBC、托业中国及韩国官方来源，不是对所有地区和所有时期的绝对断言。

- [韩国官方听读实际题页面](https://exam.toeic.co.kr/content/common/realQuestion.php)当前标注第18次公开、2026年上半年实际考题，包含Part1–7选题视频及往期批次。
- [韩国官方口语写作实际题页面](https://exam.toeic.co.kr/content/common/realQuestion.php?examCate=TOS)明确说明材料在2025年下半年定期考试中实际出现，当前第10次公开；按口语五类、写作三类任务提供视频入口。
- 两页都声明题目版权归ETS，未经许可不能引用、复制或摘取。公开观看不能推导为LANTERN可以抓取或重新发布。分类值虽按需求叫`official-past-paper`，界面应显示“官方公开实际考题（选题视频）”，并保留`collectionScope: released-past-exam-selected-items`，不能显示成“完整历年卷下载”。

## 官方样题、音频与正版书籍如何区分

[IIBC题型页](https://www.iibc-global.org/toeic/test/lr/about/format.html)明确把Part1–7网页内容称为样题。本集合细分成10个听读样题页：Part1–6各一页，Part7四页。Part1–4有原站音频播放入口；[口语样题页](https://www.iibc-global.org/toeic/test/speaking/about/format/sampletest.html)另列一个条目。

[公式TOEIC L&R問題集12](https://www.iibc-global.org/toeic/support/prep/lr_ud_12/pr.html)官方说明为ETS按正式考试相同流程制作的两套练习，共400题；这种措辞证明“官方练习”，不证明“曾经出现在正式考试”。[Speaking & Writing官方指南](https://www.iibc-global.org/toeic/support/prep/sw_guide_02.html)提供题型说明、两套练习、参考回答与解说，完整书籍收费。

[韩国官方备考书目](https://exam.toeic.co.kr/book/index.php)列有ETS定期考试真题集1000 Vol.5 LC/RC，同时也列有预测、入门及其他备考资料，因此本集合把整个书目归为`official-preparation`，不把目录内所有书或所有页面自动叫“历届原卷”。完整出版物通过正版渠道获取；没有商业书籍扫描件入口。

[IIBC官方音频使用说明](https://www.iibc-global.org/toeic/support/prep/download_audios.html)与[电脑音频下载索引](https://www.iibc-global.org/toeic/support/prep/download_audios/pc.html)说明配套音频可免费使用，按书名选择下载。它是收费教材的配套服务，不表示题目整本免费。应用端需要官方账号，电脑页提供按书名下载入口；本轮没有批量下载或逐个实播。

## 中国来源的核验结果与失败记录

[托业中国下载中心](https://www.test-toeic.cn/down.aspx)标题及目录可正常读取，列有听读与口语写作样题、手册。样题两个下载入口均返回`application/octet-stream`，Web工具无法检查附件内容。其中听读目标文件名为RAR；口语写作目标文件名为PDF，但仅凭扩展名不能宣称已验证正文或版本。故保留可靠的中文落地页，`downloadUrl`为空，并推荐上述已验证ETS直链。

另检查了[中国样题体验页](https://www.test-toeic.cn/experience.aspx)，可读取但观察到Part6三题一组等旧版特征；未放入当前推荐主目录。它是旧版官方样题来源，不能因此标记为“伪题”，但不应作为现行完整题型的依据。

详细的两个附件检查失败、一个直接路径工具错误，以及旧版页面排除记录见`CHECK_FAILURES.json`。工具不支持附件类型不等于链接已坏；工具安全打开错误也不是对网站安全性的结论。未通过其他工具绕过这些失败获取文件。

## 集成与维护约定

- `catalogue.json`是数组，包含要求的所有字段；学习步骤字段为`usageSteps`。额外的`sourceTitle`、`collectionScope`、`accessNote`、`downloadCheck`和`officialPastExamEvidence`用于防止误标。
- `parts`只表示听读Part1–7；口语写作以`skills`区分，`parts`为空。
- 全部条目为`rights: link-only`。展示标题、自写说明与步骤、官方页面链接，允许用户自己在原站使用明确提供的下载功能；LANTERN不镜像、不预缓存、不把第三方材料放进PWA安装包。
- [ETS当前许可申请规则](https://www.ets.org/legal/permissions/how-to-request.html)要求复制其材料先申请，且明确不授予公开或不安全网站复制许可。非盈利、免费或开源都不能作为自动授权。
- 学习记录应保存资源ID、书名/批次、用户自己的题号与反思；不应导入官方题目文本，也不把浏览过视频计为完成完整试卷。
- 所有元数据是本轮AI辅助核对，`humanReviewed:false`。页面可读取及PDF可打开已经验证；`mediaPlaybackVerified:false`，不宣称已在所有设备与地区实际播放。
- 将本批新增、修改、失效日期作为一次维护记录；今后重新检查链接时追加检查结果。只有拿到发布者“实际考过”的明确证据，才新增实际考题分类。把样题改名为真题不属于内容扩充。
