# LANTERN 独立美术库

美术使用自己的 `artVersion` 和主题版本管理，不混进托业题库。网页、Android、iOS、鸿蒙读取同一主题配置；在主题选择框点“浏览主题素材”进入素材库。

| 内容 | 位置 | 使用方式 |
|---|---|---|
| 空洞骑士主题、丝之歌主题、晨光阅读 | `themes.json` | 配色、构图、横竖版用途及已审核交付资源 |
| 角色、场景与 Boss 参考 | `references.json` | 原始作者/官方来源、图片直链、实际尺寸、核验日期和使用状态 |
| 可用于网页及 App 的图片 | `../public/images/` | 由主题配置引用，记录 SHA-256；不重复复制大图 |
| 生成来源与设计记录 | `../docs/ART_DIRECTION_V2.json`、本目录后续生成记录 | 提示词、原图尺寸、版本和修改说明 |

## 入库与应用

先收集 → 核对来源和尺寸 → 标记用途 → 设计主题 → 检查横/竖屏及文字可读性 → 发布。参考图片只保存链接，默认 `link-only`；可浏览不表示可打包进应用。二创保留作者原作页，未确认再利用范围时标记 `pending`。

可交付资产必须有稳定 ID、实际尺寸、SHA-256、来源、许可和 `approved` 状态。生成作品明确标注 AI 生成，仅在项目拥有的权利范围内按 CC BY 4.0 分享。游戏名称用于主题灵感归类，不代表官方授权。

现有文件的 ID 不因标题改变而更换；替换图像时新增版本文件并更新主题版本。先保留旧版本，待设备缓存和引用清理验证后再移除。原生资源只包含应用图片，不包含外部参考图。

```bash
npm run validate:art
```

该命令检查主题/参考条目、文件和哈希；它不替代视觉验收或第三方授权。与程序改动一起走 PR，但独立记录素材来源和版本，详见 `CHANGELOG.md`。
