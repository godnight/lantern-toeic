# LANTERN 主题素材库

美术版本 0.3.1，与应用版本分别管理。当前四套角色主题使用用户提供的 AI 同人插画：蓝湖、白花、雪山、水晶山峰。每套包含横幅、手机横幅和缩略图，共 12 个 WebP，合计 1,483,078 字节。

桌面横幅保持原图 1672 × 941，手机图为 960 × 540，缩略图为 480 × 270。仅等比压缩；不裁切、不放大。页面在窄屏将完整横幅放在文字之前，桌面用主题焦点调整展示位置。

配色 ID hollow / silk / paper / crystal 分别为深蓝圣巢 / 绯红丝歌 / 晨光书页 / 晶紫微光；既有偏好可以继续读取。图片由 map-scenes.json 按栏目独立选择：今日蓝湖、训练水晶山峰、复习原有泪城、成长雪山、书库白花。原三张任务图与休息图保留，配色切换不替换这些场景。小骑士与黄蜂女不出现在同一套主题；蓝湖中的奎若是原有支线场景角色。

## 来源和许可

这四幅图由用户从既有素材中选定并授权本次集成和 GitHub 提交。它们是 AI 生成的同人图，不是官方游戏原画；底层角色等权利仍属于各自权利人，不能套用项目题库的 CC BY 4.0 或代码的 MIT 许可。每个文件均独立记录来源、许可说明、尺寸和 SHA-256。外部参考库保留 19 条入口，仅存链接。
