# 个人完整听读题包

入口：训练之境或学习书库 → 完整听读模考。Web 使用当前登录账号的本机空间；鸿蒙使用应用本机空间。本机导入不会自动上传。v0.3.3 可由用户在[个人题包库](EXAM_LIBRARY.md)明确上传完整题包，D1 保存账号私有目录，R2 保存题包文件（含题文、答案及音频），再按需下载到其他设备。作答、考试记录和完整备份仍保存在本机，不随题包云同步；材料不进入 GitHub 或公开安装包。没有预装官方完整真题。

## 使用流程

1. 选择一份或多份完整题包 JSON，或从个人题包库“下载到本机题包”；每份独立校验和保存。同 ID、同版本、同内容重复导入不会增加副本；改版须递增版本。鸿蒙可在系统浏览器登录网页版下载 JSON，再回 App 导入；这不是百度网盘直连或原生账号同步。
2. 打开题包，完成音频试听与图片解码预检，确认声音可听清、材料完整。
3. 听力按本套显示的时长截止，未声明的旧题包为 45 分钟；阅读固定 75 分钟。不能提前进入阅读或返回听力；后台、退出和重启不暂停。恢复听力按已经过的时间定位，并记录中断。
4. 阅读阶段可确认提前交卷，到时自动交卷。只有保存成功才显示成绩、答案与解析；漏答按错误计。首次与复测保留为独立记录。
5. 题包首页导出完整备份，检查系统下载文件确实存在。备份包含私人题文、答案、音频与记录；不要公开分享。当前只能在同一记录范围恢复，不提供 Web 与鸿蒙跨账号迁移。

本机记录无法提供监考或可信防改时间。Part 用时包含后台驻留时间，不能当作有效学习时间。正确题数不套用通用公式换算为托业分数；仅在题包附有出处明确的该套参考表时显示参考区间。

## JSON 格式 v1

这是已整理的数字题包导入器，不是 PDF OCR。已有合法可用于个人整理的完整 PDF 时，可用[电脑本地原页打包工具](EXAM_PAGE_PACKER.md)，将页面、整场音频和人工核对的答案/题组映射生成 JSON；不用逐题抄写正文或手工编码 base64。自有纸质书仍需先准备相应电子材料。正文与图片均支持；导入者须确认有权以该方式个人使用。官方公开原样 PDF 的个人下载许可不自动代表可拆题重排或公开传播。

| 字段 | 内容 |
| --- | --- |
| `kind` / `schemaVersion` | `lantern-toeic-exam` / `1` |
| `id` / `version` / `title` | 1–80 位字母数字下划线连字符 ID；正整数版本；标题 |
| `source` | `classification`、`title`、`rightsStatement`；可含 `publisher`、`reference` |
| `format` | 可选；省略为现行题型，显式 `"legacy-2006"` 为 2006 版旧题型；不接受其他值，不自动推断 |
| `assets` | `{id,mime,base64}[]`；原始文件的标准 base64，不含 data URL 前缀 |
| `listeningAudioId` | 本套整场听力音频的素材 ID |
| `listeningDurationMs` | 可选：已核对完整音轨的听力时长，毫秒安全整数、整秒、40–50 分钟；缺字段为旧默认 45 分钟 |
| `groups` | `{id,part,questionNumbers,passages,imageIds}[]` |
| `questions` | `{number,part,groupId,prompt,choices,answer,explanation?}[]` |

`classification` 为 `official-past`、`official-practice`、`original` 或 `other`。官方分类还须填写出版社和具体版次/套号/来源。来源均由导入者声明，程序不会据此认证正版或再分发授权。所有文本按纯文字显示。

题号必须连续 1–200。省略 `format` 保持现行题型及旧包的规范化字节、指纹；只有显式 `format: "legacy-2006"` 才启用旧制规则。Part 2 三选项，其余四选项；`answer` 从 0 开始。Part 1/2 的口述题干可留空，口述选项可填 A/B/C/D 占位（Part 2 仅 A/B/C）。每题恰好属于一个题组，题组题号连续且不能跨 Part。

| Part | 现行题号（数量） | 旧制题号（数量） | 题组规则 |
| --- | --- | --- | --- |
| 1 | 1–6（6） | 1–10（10） | 每组 1 题，必须有图 |
| 2 | 7–31（25） | 11–40（30） | 每组 1 题，三选项 |
| 3 | 32–70（39） | 41–70（30） | 每组 3 题 |
| 4 | 71–100（30） | 71–100（30） | 每组 3 题 |
| 5 | 101–130（30） | 101–140（40） | 每组 1 题 |
| 6 | 131–146（16） | 141–152（12） | 现行每组 4 题，旧制每组 3 题；均恰好一份材料 |
| 7 单篇 | 147–175（29） | 153–180（28） | 恰好一份材料；现行每组 2–4 题，旧制每组 2–5 题 |
| 7 多篇 | 176–200（25） | 181–200（20） | 每组 5 题；现行 2–3 份材料，旧制恰好 2 份材料 |

Part 7 题组不能跨单篇/多篇边界。`passages` 存完整纯文字；扫描图可用空字符串占据材料份数并引用图片。Part 6/7 必须有正文或图片。旧制 Part 6 若原书采用 3 组各 4 题的变体，目前不符合本模型，不能强改题组凑成支持格式。图片没有自动 OCR 无障碍文字，宜同时提供正文。旧题型单独标注和按其 Part 题量判分，用于补充训练，不替代现行考试基线。

允许 PNG、JPEG、WebP、MP3、WAV；禁止外部资源、SVG、HTML、脚本和未引用素材。校验结构与可解码不能证明材料正确或完整，音频声音与题文答案对应仍需人工确认。

声明听力时长前须确认音轨完整且与题本匹配，再将完整媒体秒数向上取整、乘以 1000。App 预检要求实际音轨不长于声明，且差值至多 1.5 秒；超出时阻止新开考，不能以删音频或变速来通过。无声明旧包实际音轨长于 45 分钟也不能新开考，须核对后制作带声明的新版本。40–50 分钟是本产品的防误填范围，不是官方考场规则；背景见 [RFC 0006](rfcs/0006-complete-listening-duration.md)。

时长属于题包指纹，修改须新版本；已开始考试的截止不改写。新版支持旧题包与旧备份，但带声明的新包要求新版 App。存储升级后，旧版 App/旧页面会拒绝打开模考库，请升级或刷新，不要卸载或清空数据。

本机限额：单题包 JSON 96 MiB，音频 50 MiB，单图 6 MiB，解码素材合计 64 MiB，最多 100 素材；每个本机账号范围 20 套、192 MiB 规范化 JSON 和 1000 次记录；完整备份 224 MiB。云端个人题包库另为每账号 32 份 / 2 GiB，每份仍不超过 96 MiB，不会扩大本机容量。设备实际配额可能更小，低内存手机大文件尚未验收。失败事务不会留下半包或覆盖旧答题。

可显式移除未作答的本机题包以腾出空间；该 ID/版本已有进行中、首次或复测记录时禁止移除。云端移除须明确确认，不删除已经导入本机的题包或记录。不要通过清数据、卸载或删除有记录的题包腾空间。

可选 `scoreRanges` 为 `{source,listening,reading}`，两科数组各项 `{minCorrect,maxCorrect,minScore,maxScore}` 连续覆盖 0–100；分数 5–495、步长 5、单调。仅填写该套材料提供的有出处参考表。

## 开发与测试

核心为 `lib/exam-model.ts`、`lib/exam-storage.ts`，UI 为 `app/learn/mock-exam.tsx`、`lib/exam-ui.ts`。独立 IndexedDB 名称仍为 `lantern-private-exams-v1`，数据库版本升至 3；升级不改写已有题包或记录。答题只读取不含大音频的目录，事务完成后才提示保存。不要用清空整库来处理恢复错误。

执行 `npm run test:exams`。浏览器回归先执行 `npm --prefix mobile run build`，安装 Playwright Chromium 后运行 `npm run test:browser`；使用专用本机端口 4175 和全新上下文，报告默认在系统临时目录。CI 每个 PR 和 Release 自动执行。`tests/fixtures/synthetic-exam.cjs` 仅供自动化控制变量，不含真实试卷，不得复制到 public、产品题库或发布附件冒充真题。开发测试与浏览器、模拟器、真机和两小时媒体验收分别记录。
