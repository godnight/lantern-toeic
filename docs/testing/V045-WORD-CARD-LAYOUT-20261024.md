# v0.4.5 定向验证边界

单词卡组件自测验证实际 TSX 的提交边界：正常等待不提示重试、不提前揭义、不重复提交；真实失败保留原评分重试；保存确认后再揭义；下一词保持独立操作。阅读位置只在词条或分区变化时重置，揭义后焦点进入内容区，切词后焦点进入标题。

实际界面验收要求在 320×640、390×844、宽屏、短屏及 200% 字体条件下记录连续十词的答前、等待、答后及下一词几何。外框与底部操作目标同条件变化不超过 2 CSS px。长内容、可触达按钮、至少 44px 点击区、横向溢出、正常等待与失败原评分重试均须检查。浏览器合成工作流仅证明组件与布局，不能替代真实 SRS、存储及 ArkWeb 媒体播放验收。

主题回归须保留四主题持久化、今日主要入口、蓝湖完整构图及八张新派生图的真实解码和加载占位；原 PNG 与旧冻结交付不变。内容与全部自然媒体仍由原校验和冻结差分保护。

远端 CI 的浏览器证据与实际截图交小测独立核收。保持现有本地浏览器停止边界，不为验证绕用新 URL 或设备。录音、短信供应商、私有线上访问与原生签装不纳入本轮局部通过结论。
