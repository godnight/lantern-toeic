# 完整音轨计时兼容验证

日期：2026-10-11。对应 [Issue #37](https://github.com/godnight/lantern-toeic/issues/37) 和 [RFC 0006](../rfcs/0006-complete-listening-duration.md)。当前记录本机模型、存储、打包器及浏览器结果；新版 HAP、模拟器覆盖升级、GitHub CI 和发布还需单独完成。

## 风险与验证设计

| 风险 | 检查 |
| --- | --- |
| 完整音轨被旧 45 分钟截止提前停止 | 可选 45:53 声明，边界模型前后 1 毫秒；真实可解码 45:53 合成 WAV 在 45 分钟后继续播放，新截止才停 |
| 改时长导致旧题包指纹或历史失效 | 原模型已知规范化 SHA、原版 packer 45,184 字节固定 SHA；旧库升级逐行比较且禁止任何行写入 |
| 备份或旧代码改变截止 | 混合新旧备份、重复恢复、后续答案保护、时长/截止篡改的原子拒绝；旧 IDB 版本重开失败 |
| 音频与声明不符仍可开始 | 真实短媒体与长声明不符、无声明长媒体，两种 UI 都保持 0 考试且按钮禁用；事件/来源/账号切换立即撤销预检 |
| 冷启从头播放或重给考试时间 | 实际关闭并新建页面，保留绝对截止；音频恢复到约 2703 秒并真实推进，阅读仍完整 75 分钟 |

## 实际结果

- 模型/存储新增 14 项，首次在旧代码为 2 过、12 败；实现后原 32 项加新增共 46 项通过。UI 新增 12 项，原 27 项共 39 项通过；其中媒体 hook 为离线 double，不代替浏览器结果。
- 集成后的完整 `test:study` 对应 11 个测试文件共 229 项通过，0 失败/跳过；完整 TypeScript 检查通过。packer 共 31 项，真实模型在渲染前拒绝非法时长。
- 原版 `69e7f6f` packer/model 与同一合成配方和假渲染器产生 45,184 字节 JSON，SHA-256 `e61563d19bc8aaa9260a26d18f3561b30e03f94b1d043b1a23b733ddd1bd0707`；新实现固定断言原始字节长度和此 SHA，旧配方未改变。
- Web 和鸿蒙共享前端构建通过。保留既有大 chunk 提示；共享离线音频校验 448 段通过。这两项不是 HAP 编译或部署证明。
- 原创、允许打印的保护 PDF 经实际 Poppler 渲染 7 页并打包 200 题，通过新实现解析。完整 Chrome 回归共 26 项通过：原 22 项、4 项新增时长流程；页面错误、HTTP 错误及外部请求均为 0。
- 新增时长流程使用真正 45:53 的 8kHz/8-bit 单声道静音 WAV，实际读取 duration、点击原生播放器、导入/保存/恢复均通过界面。45 分钟后仍播放；冷启后观测位置 2703.132 秒，对应原起点应在 2703.058 秒。声明截止锁听力并暂停音频，阅读截止自动交卷，总用时 7,253,000 毫秒，200 题未答。

浏览器首轮因测试夹具父目录尚未创建，在 17 项既有检查之后遇到缺文件错误；未到新增时长验证。补齐夹具、真实转换成功后，第二轮完整 26 项通过。两轮结果均保留，不把首轮计作通过。Windows 清理帮助进程出现 5 秒超时警告，runner 使用有界直接终止且确认 preview 进程退出；不声称枚举了全部后代进程。

## 边界与接续

合成题目、静音 WAV、桌面 Chrome 和浏览器时钟推进只验证代码与媒体兼容；不证明真实卷音频与题文逐题匹配、人耳音质、自然两小时耐久或 Pura X Max 硬件。候选实际音轨的末题位置、来源及配对另行核验；没有裁切或变速真实音频。

私人证据在 `vocab-work/listening-duration-acceptance-20261011/`，浏览器第二轮为 `browser-second/result.json`；模型和 UI 红绿记录、旧 packer 基准在两份对应私有 proposal 目录。没有使用物理手机或已有长期合成模考的模拟器。发布前须完成专用内容模拟器覆盖升级和最终提交的 CI，记录新版本产物及校验值。
