## 跨页面共同检查

1. 320 / 390 / 1440 为最小代表矩阵；768/1024、200%/文本间距与真实折叠/软键盘证据另列，不从缩图推定。
2. 正文16px、长材料17–18px；普通页面标题32/28、词头40/36；必要来源/保存/范围/题型/错误13–14px；小导航标签例外11–12px。
3. 44px 可操作命中区与手机48px主操作；分段控件的可见高可以较小，但点击目标实测需足够。
4. 无横向页面滚动、长文字不截断、底栏/对话框操作不遮挡；题页图的独立双向滚动单独判。
5. 成功/选中/错误有文字图标，不只靠颜色；错误独立 danger-soft 面；不降低只读解析对比度。
6. `body/html[data-ui-theme]` 与 Dialog Portal、mock-shell 的 computed tokens/font 完整；legacy `!important` 以最终computed值为准。
7. 聚焦学习 surfaces 无艺术；无常驻背景动效、外部字体和默认游戏图；减弱动态策略仅按已见证据评价。

## 静态候选，待实图与 DOM确认

这些不作为已确认的渲染缺陷，最终 CSS 级联可能有覆盖：

- `workspace-redesign.css` 中 `.practice-dialog .passage` 使用 Georgia / Times New Roman serif，偏离统一系统无衬线规则。
- `.main-tabs` / `.lesson-tabs` 的 trigger 规则 min-height40px，需检查命中区是否达44px；legacy覆盖另查。
- `@media(max-width:350px)` 普通标题26px，较冻结28px小；必要指标/状态多处11–12px需按内容分类。
- `workspace-main` max-width1320，规格建议max1200含padding；1440时实际阅读宽度是否过宽需亲见。
- ordinary `WorkspaceHeading` 使用 flex 而非 `.ui-theme-heading`，320依赖absolute motif + eyebrow padding；无 eyebrow普通标题是否有碰撞需确认所有实际页。
