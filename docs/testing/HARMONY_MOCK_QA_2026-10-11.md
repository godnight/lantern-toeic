## 缺陷闭环

1. 首次真实 smoke 在等待词库“本机保存”状态时失败。布局与截图确认实际停在“温故知新”：词库入口被固定底部导航遮挡，旧 runner 将祖先裁剪后的范围当作可点击区域，点击了覆盖其上的导航。修复对同一 Web 内已知“主导航”和“学习状态”遮挡进行扣除，将实际点击、输入、滑动和定位统一使用可操作区域；完全遮挡时先有界滚动并重新定位。保存原失败记录，针对用例先失败，修复后33项离线检查通过。
2. 进一步审查发现独立滚动容器来自旧布局，而遮挡计算使用新布局，无法正确关联同一 Web 对象。修复在单次滚动中保持节点和布局来自同一快照；针对用例先失败，修复后35项离线检查通过。随后重新执行最终真实 smoke，结果 passed。

这两个问题属于测试 runner 定位与布局快照问题；本轮未通过修改 App 状态文案、放宽成功条件或清数据绕过失败。两阶段测试数为各次执行结果，不能相加为68项。

提交前类型检查与 `git diff --check` 通过；代码和报告经独立只读复核。GitHub CI 的最终结论以对应 PR 为准。

## 备份证据

四份真实导出文件的大小分别为3,724,440、3,724,578、3,724,578、3,724,578字节。`backup-proof.json` 记录逐文件SHA及 passed 结论。各份均含两套包、一条本次记录、两道已答题；听力截止与起点相差2,700,000毫秒，整卷截止相差7,200,000毫秒。

核对字段：`id/ownerId/examId/examVersion/fingerprint/ordinal/startedAt/listeningDeadline/readingDeadline/answers`。比较包括答案的 `savedAt`；`lastObservedAt`、`revision`、题目驻留时间不倒退，已有中断不丢失。题包来源为合成QA数据，不用于学习评估或真实成绩。

升级前及结束后“成长足迹”均可见听读首次作答2题、口语录音0段，结束复核还滚动到无导航遮挡的位置再取证。这是UI计数保持，未做全部旧数据逐字段导出对比，不扩大为完整迁移证明。合成模考的两道答案没有混入原学习首答计数。
