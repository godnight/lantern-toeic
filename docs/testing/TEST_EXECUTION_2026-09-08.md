## 发现、修复与复验

| 缺陷 | 影响/修复 | 复验 |
|---|---|---|
| QA-001 UUID不可用 | HTTP环境randomUUID缺失令作答失败；共享createId以getRandomValues生成v4备用ID。 | 浏览器重新答题/打卡成功；100个ID格式/唯一性回归通过 |
| QA-002 复习拆组 | 复习单题绕过完整篇章；两处入口都展开同Part题组，保留源顺序。 | 实际Part6整组、不引入无关题回归通过；组浏览器流程未测 |
| QA-003 单项JSON损坏影响全部记录 | 改为逐项解析，保留合法快照/日志及坏原件。 | 健康作答在坏profile/录音元数据旁可恢复；不声称任意schema修复 |
| QA-004 本机录音缺失错误回退云API | 只有已登录且已上传的录音才回退API；否则明确提示。 | owner=null缺Blob拒绝而不请求云API回归通过 |
| QA-005 未保存可重录覆盖 | 保存成功前禁用再说一次，保留原Blob重试。 | 保存失败仍禁用；同ID同Blob重试；保存后重录恢复，通过 |
| QA-006 迟到GET覆盖新设置 | 请求前后比较本机profile，保护另一标签已确认的新值；不增加轮询。 | 两标签隔离harness复现后修复；新值保留、仅1次GET、无timer，通过 |

源码复核由独立代理只读执行；QA-006来自模拟延迟storage事件，未假称真实云同步复现。
