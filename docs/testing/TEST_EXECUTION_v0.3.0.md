## 测试设计

| 风险 | 验证方法 |
| --- | --- |
| 不完整/错分组题包被当作整卷 | 200 连续题号、七个 Part、选项、题组、必需图片/文本/音频、MIME/大小/来源字段校验 |
| 换账号泄露、异步旧回调写入 | 双 owner 与不同页面队列、关闭后的迟到读取/写入、提交前后 revision |
| 保存失败虚报成功 | IDB 写入/备份中段注入配额错误，检查整批回滚与旧记录不变 |
| 后台延长时间、越阶段作答、提前泄答案 | 固定截止、冷开、时钟回拨、到期点击、听读边界、交卷前 DOM/SSR |
| 音频/图片坏文件仍开考 | 实际音频事件、逐张图片解码、失败/超时/取消、StrictMode setup→cleanup→setup |
| 恢复备份破坏记录 | 同包幂等、同 ID 不同内容拒绝、旧备份不覆盖新答案、未来时间容差 |
| 小屏操作不可达 | 目录、听力、阅读、成绩的 320/390/768px 浏览器检查与截图 |
| 自动发布半套附件 | 草稿重试、SHA 校验、签名私有包拒绝公开、已公开版本不可覆盖 |

合成题包只作控制变量，音频为短静音 WAV；不用于证明真实试题、声音清楚或完整听力内容。时间快进用于计时边界，不作为两小时连续运行证据。

## 执行与缺陷闭环

- 核心模考 32 项：解析/结构、阶段/成绩、实际 TypeScript 与 fake-indexeddb 事务、配额/并发/备份/账号隔离。
- UI 辅助与真实 TSX 27 项：FIFO、owner 关闭、答案泄露、HTML 纯文本、媒体 cleanup、图片解码与退出失败。
- 原学习/词库回归 75 项，加整页模考入口隔离 1 项，`test:study` 共 135 项通过。
- 原生/工具链 16 项、HAP 校验器 6 项、设备 runner 离线 27 项、Web 产物 5 项、发布脚本 24 项、构建超时清理 15 项通过。合计 228 项机器测试，另计浏览器流程；不混入历史真机验收次数。
- TypeScript、内容与美术校验、Web 生产构建、鸿蒙共享构建通过。490 项资源包含 448 段既有内置音频；没有加入私人整卷媒体。

发现并修复：

1. 进行中备份在不同时刻重复恢复因 revision 次数误报冲突；新增用例先失败，归一化实质状态比较后通过，真实新答案仍防覆盖。
2. 明显未来的备份可能锁住本机一年；导入时拒绝开始/观察时间超过当前时间 5 分钟的整批备份，先红后绿，并验证原库不变。
3. StrictMode 清理媒体 src 后二次 setup 不恢复；恢复实际元素 src 并测试 ref 先被清空的顺序。
4. 单看图片文件头不能证明可读；增加 load/decode/尺寸/超时/取消门禁，开考前检查全部图片。
5. 退出时写中断标记失败会困在模考；保留错误并提供明确“仍退出（计时继续）”操作，不虚报保存成功。
6. 鸿蒙旧下载白名单拒绝模考备份；仅允许固定 `lantern-exam-backup.json` 和 JSON MIME，正向用例旧版失败后修复通过，非法路径/MIME/来源仍拒绝。

初次全量旧组件测试因未注册新 MockExam 模块替身而失败；补齐测试依赖后重新执行 135 项通过，没有放宽原业务断言。

可重复运行的脚本纳入仓库 Core 与 Release 门禁，最终次数及截图以该提交的 CI `browser-qa` / `release-browser-qa` artifact 为准。使用独立本机端口、独有服务实例标记和临时目录；端口被占时失败，不接管用户服务。只上传合成测试结果和截图，不上传私人材料。
