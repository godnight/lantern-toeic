- 桌面主场景高 380px，角色在左、学习入口在右；手机和平板将完整横幅与文字上下排列。白花桌面焦点已调整，避免裁掉黄蜂女头部。

## 审查中修复的回归

1. 手机顶部恢复安全区：独立 CSS 验证 48px inset 时实际 paddingTop 为 58px。
2. 动效关闭隐藏整个装饰层，避免暂停的关键帧 opacity 覆盖普通 opacity；非蓝湖主题不显示水纹。
3. 同时订阅浏览器可见性和原生桥状态，覆盖鸿蒙后台但 document.hidden 仍为 false 的情况。
4. IntersectionObserver 同批出现不可见→可见时采用最新条目，避免 840px 实际浏览器流程中错误停留在暂停状态；有独立复现和行为回归。
