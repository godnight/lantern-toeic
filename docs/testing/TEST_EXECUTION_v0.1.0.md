本次 v0.1.0 的机器构建与验证以对应 GitHub Actions 运行、`build-info.json`、`package-verification.json` 和 `SHA256SUMS.txt` 为准。流水线全部成功、附件上传并复核后才公开 prerelease。公开 HAP 为未签名离线调试构建，不含个人设备授权材料；手机已安装的私有签名包继续单独保留。

## 设备自动化状态

runner 使用显式设备与准备状态，默认不收藏、不评分、不删数据；专用测试设备模式才允许新增测试事件。布局文字和可见区域定位代替固定坐标，失败保留布局、截图和应用日志。备份幂等比较三份实际导出的事件 ID 与内容，不以提示条代表数据正确。

自动化脚本 27 项离线测试已执行；首次 live runner 验收尚未通过。本机模拟器 `LanternOffline7` 当前停止，CLI 启动要求确认新的模拟器协议；用户休息期间先登记，不绕过协议，也不操作用户真机。仅此设备 UI 层待验不妨碍进行源码、构建与包体门禁，但 Release 说明必须保留此限制。

另以 Windows SDK 26 成功构建新的本地签名包（0.1.0 / 20005），19,161,252 字节，SHA-256 `01d88062d3e7f3f4ce4d91708a7993080ed2c1f710bc4b3cd351460a376a7da3`，490 项资源匹配；尚未安装到手机。该包只保存在本地交付目录，不进入 GitHub。
