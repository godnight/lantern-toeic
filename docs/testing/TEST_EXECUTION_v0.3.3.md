## 发现、修复与回归

- Cloudflare 压缩会使 Content-Length 缺失或改变：下载设置 no-transform，客户端仍按实际解码流长度和 SHA-256 验证。
- 云目录清理失败可能丢失重试入口：改为可重试墓碑；上传提交失败、取消与清理失败分别回归。
- 下载失败后残留“正在下载”：失败时清除进度提示，最后 5 条浏览器回归与组件检查通过。
- 旧测试浏览器桩缺新模块和 URL 环境：补全测试桩，没有修改产品逻辑规避测试。
- Tomato 原 MP3 头部估时低于完整解码结果：以全 PCM 帧数核对原音频与未裁切转码音频，再核验重新封装后的媒体时长。
- Tomato 第一版四舍五入导致部分声明短于实际音轨：最终 version 2 向上取整；独立比较确认只改变版本号和时长声明。真实应用时长门禁九套通过，18 个声明偏短/偏长负例正确拒绝，浏览器媒体时长另行通过同一门禁。
