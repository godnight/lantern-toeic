# 个人题包库

在“训练之境 → 完整听读模考 → 个人题包库”上传整理好的完整题包 JSON。云端文件只属于当前登录账号；每份最多 96 MiB，总计 32 份 / 2 GiB。上传时先在浏览器检查题目结构、媒体和答案，再由 R2 校验文件 SHA-256；服务器不在内存中展开大型 JSON。

电脑或手机网页可以“下载到本机题包”开始离线作答，也可“下载 JSON 文件”保存文件。鸿蒙 App 的“在浏览器打开个人题包库”会打开网页版；登录后下载，再回 App 使用“导入题包 JSON”。原生 App 尚未具备独立云认证，不会静默读取百度网盘或持有网页服务令牌。

云端同步对象只有题包，不含用户作答和考试记录。卸载、清理浏览器或换设备前请导出完整备份；有记录的本机题包不能移除。未开始作答的本机题包可以显式移除，腾出空间后再按需下载。云端移除也需明确确认，不影响已经导入的本机文件或成绩。

当前格式为 Part 题量 6/25/39/30/30/16/54；`format: "legacy-2006"` 明确启用旧题型 10/30/30/30/40/12/48。遗漏 format 仍按现行题型严格校验，不自动猜测。旧题型有独立 Part 判分，展示为补充练习，不与现行考前基线混淆。

下载失败不会导入半份文件；重试先检查实际字节数、SHA-256 和完整题包结构。相同内容上传去重；同 ID/版本不同内容仍拒绝覆盖。暂时中断的上传会在目录显示，刷新后可取消并重试。云端目录元数据由上传者填写，完整导入再验证；来源声明不等于认证真题或再分发授权。
