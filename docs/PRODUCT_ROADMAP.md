# LANTERN v0.3.0：把材料、错因与下一次练习连接起来

研究日期：2026-09-08。目标：听读 >650、口语 ≥130；通常每天 25 分钟，忙时最低 5 分钟。本建议基于四款产品的官方公开网站及帮助中心，以及本地现有代码的只读核对。没有登录第三方付费账户或宣称完成其手机实机体验；没有采用宣传准确率、平均提分或保证达标数字。

建议 v0.3.0 聚焦两个交付：**可恢复的今日学习计划**，以及**错因与不确定题的标记复习**。已有逐句回听、听写、录音和间隔复习可直接串入新流程，优先让现有内容真正被学完。

## 最小范围与优先级

**P0：错因与标记复习。** 答案提交后显示两个轻量操作：“想再练一次”可开关；“这次卡在哪”可选一个错因，也可跳过。错因先限于没听清、词汇不熟、语法判断、没找到依据、读题或时间五类。答对时也能标记，不能把标记改写成答错。备注限一条短句，避免填写负担。

复习页增加“今日到期 / 上次答错 / 我的标记”筛选，并能按错因过滤。开始复习时冻结本轮筛选结果；一次只开一个小组，结束后用户决定是否继续。错因对应现有训练入口：没听清→一句回听与听写；词汇不熟→本题词汇；语法/依据→解析与证据；时间问题→下一次先限时作答。手动标记保留到用户取消，不能因一次答对自动消失。

**P0：可恢复的今日计划，含资源任务。** 首页明确列出当前步骤和下一步；退出、刷新、外链返回后可继续。资源卡增加“加入今天”，加入后提供“打开材料→完成一个具体任务→记时与收获”。点击外链只表示打开，不自动算完成。资源任务替换当天同技能的一项练习，不额外叠加时长。

今日安排使用可解释的本地规则：优先到期与标记，再轮换新题；显示原因如“这题上次没听清”。只有极少量首次作答时用“继续收集练习记录”，不要据一道错题下“最薄弱能力”的结论。v0.3.0 不需要训练预测模型，也不新增分数预测。

**P1：口语回听完成点。** 复用现有口语录音能力，在 25 分钟计划末尾进入一题，回听后选择一个待改善点，如内容完整、组织清楚、表达连贯或清晰度。允许再次录制并关联前一段；若实现成本超出本版，先交付“进入口语→保存→回听→记一个改进点”，双录音对比排入下一小版本。

**后续版本：** 独立词汇本、可选择任意句的听写、更多原创整组材料、经真实试用后调整推荐规则。完整模考和自动口语评分需要足够内容及单独验证，不能拿少量练习直接推算达标。

## 对应 25 分钟与 5 分钟的可执行路径

以下是本项目的建议时间预算，可由实际完成速度调整，不是官方备考保证。

| 时段 | 25 分钟标准日 | 完成条件 |
| --- | --- | --- |
| 5 分钟 | 复习一个到期/标记小单元 | 重答后说明一个依据或确认一个错因 |
| 8 分钟 | 一组听力及一个精听点；或已加入计划的听力资源任务 | 完成整组，不截断对话三题；至少回听一个卡点 |
| 7 分钟 | 一组阅读及一个依据；或对应阅读资源任务 | 提交答案并查看依据；Part 6 保持四空全文 |
| 5 分钟 | 一项口语任务，录音后回听 | 保存录音，记录一个改进点 |

最低 5 分钟模式只保留一个完整小循环：约 1 分钟回想旧知识，2 分钟做一题独立短题并理解，2 分钟读出或简述答案。可在听力短题、阅读短题和口语中选择；不要在时间不足时硬塞一整篇长阅读。开启最低模式不伪造当天听、读、说三项全部完成；缺一天也不累计补课债。

## 版本与数据管理建议

本报告是建议，不表示以下修改、版本或标签已经存在。先完成当前鸿蒙适配、维护与官方资料修复，再从通过 CI 的提交切出 `feat/v0.3-study-loop`。按“数据与迁移→标记复习→资源计划与日程→发布验收”提交，便于逐项回看和回滚。

产品版本使用 `0.3.0`；题库 `contentVersion` 保留自己的版本，纯流程更新不把旧题全部改版本。持久化数据另设显式 `schemaVersion`。为题目标记增加 `qid / flagged / reason / note / updatedAt`，为资源任务增加 `resourceId / plannedDate / status / minutes / updatedAt`；首次答案仍保留在不可覆盖的 Attempt 历史中。资源任务用稳定 ID，避免重命名导致学习记录失联。

新字段必须覆盖本机读写、跨标签合并、待同步操作、服务端验证/存储、导出与恢复。旧数据缺字段时补空值；迁移执行两次结果相同。取消标记和取消计划也要可同步，不能只做客户端删除后被远端旧状态恢复。旧 note 中的资源记录保留原文，若转为结构化记录应去重且不重复累计分钟。

合并后再写 `CHANGELOG.md`：列出用户行为变化、迁移方式、验证结果和已知平台限制。CI 通过且三个验收场景完成后才创建 `v0.3.0` 标签和发布说明；补丁修复进入 `0.3.1`。发布说明必须区分浏览器已验证与鸿蒙真机已验证，不能用网页预览替代鸿蒙安装、返回键、录音授权和升级保留数据的确认。

## 三个具体版本验收场景

1. **今日计划与预算。** 设置 650+ / 130、25 分钟；加入一份听力资源后，计划总预算仍为 25 分钟。打开外链不会自动完成；返回并记一笔才完成该步，随后能继续阅读与口语。刷新仍回到未完成步骤。5 分钟模式可完成一个完整小循环，P3/4/6 队列没有被截成半组。

2. **猜对题也能复习，首次成绩不变。** 一道题首次答对但标记“想再练一次”，另一题答错并选择“没听清”。刷新后两者仍在对应筛选里；由“没听清”进入能打开逐句回听。第二次答对只新增复练记录，首次正确率不被覆盖；取消标记后跨标签、重启和同步不会重新出现该标记。开始复习后的当前队列不因中途切筛选而跳题。

3. **旧数据升级与发布可追溯。** 用包含旧作答、资源 note、录音与待同步操作的测试数据升级，记录数量和分钟总数保持正确；两次迁移无重复；切换账号不串数据；离线写入新标记和计划后恢复网络可同步。CI、构建与资源检查通过，变更日志、迁移说明和 `v0.3.0` 标签指向同一发布提交。鸿蒙真机未测项目明确列为未验证，并在真机完成返回、录音授权、升级留存验收后才宣称支持该场景。

## 可借鉴的流程与不能照搬的内容

本版以原创界面与现有原创练习实现以上通用学习动作。第三方试题、答案解析、教材页、课程讲义、音频、视频、词典例句、完整截图与品牌视觉不导入本地题库，不缓存或重新分发。公开可访问不等于取得再发布许可。资源卡保留官方标题、入口链接、核验日期及自行撰写的使用步骤；需要付费的材料在原平台合法使用。只有明确拥有再利用权的素材才进入内容包，并保留授权与来源元数据。
