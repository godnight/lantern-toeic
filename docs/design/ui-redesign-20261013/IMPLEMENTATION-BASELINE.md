## 4. 数据与接口不可变项

遵守[规格12.1/12.2](./DESIGN-SPEC.md)：学习`lantern-v1-<owner或device>`及profile/op/ack/recording/sync/required-schema派生；词库owner编码prefix/device prefix；录音`lantern-audio`v1/audio/`studyKey:recordingId`；模考`lantern-private-exams-v1`v3、packages/catalog `[ownerId,key]`、attempts `[ownerId,id]`及owner索引。Harmony模考范围`harmony-local-device`、Web当前owner、无owner拒绝。

原wordId/事件ID/recording发生时间/题包版本fingerprint/考试ID/ordinal/revision/原截止不重建或迁移；主题仅持久化paper/crystal/hollow/silk，day/night只是UI tokens，继续theme-only。读取失败不可当空库后覆写；IndexedDB abort、R2/D1同ID风险留既有架构线处理，UI实施不得扩大为存储重写。

三类备份分开：学习JSON无录音Blob、无新增学习恢复UI；词库events独立导入导出；完整模考含owner/packages/attempts及题图音频，仅同范围恢复。192MiB本机题库与224MiB完整备份限制不同。失败时下载当前录音Blob是恢复动作，不是新增云备份。
