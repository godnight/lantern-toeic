## 学习完成与退出：实际字段校对

末题的既有能力（`app/learn/practice.tsx:41`）：本组答对数/题量；样题不换算正式成绩；「记录时间与收获」打开打卡，「先休息一下」关闭，已提交答案仍保留。

既有打卡（`app/study-app.tsx:60`、`:108`）只包含以下用户可编辑字段：

1. **实际学习分钟**：必填整数1–240；预填从本组开始到完组的经过分钟，用户可修改。这不是已经写入成功。
2. **今天的负荷**：轻 / 刚好 / 重，默认刚好。不是心情评分。
3. **一个收获或卡点**：可空，最多1000字。

记录含 id、配置时区当日date、minutes、load、note、createdAt。普通题组不带材料ID；资料打卡才加已有 `[资源:id]` 文本。成功才关表单，取消打卡不撤销已保存答案，账号同步状态另外说明。原型应按这些字段绘制，不能增加“自动计时已保存/心情/题目错因/学习任务API”。

词卡评分保持「先翻卡，再还没记住/记住了」，成功落盘才下一张；失败不得增完成数。完组显示已评价张数，退出未评价卡不算完成，提前自测不升级间隔。其现有题组游标也不承诺重启恢复。

## 搜索状态覆盖判定

| 状态 | 当前代表稿/代码 | 判定 |
|---|---|---|
| 初始 | 有独立提示、输入框与两范围 | 方向足够；不应自动弹键盘 |
| 输入与IME | 监听compositionstart/end，组合阶段不刷新 | 结构合理；`input`代表稿的文本值须修正，真实中文输入法尚未验 |
| 首次词典加载 | loading骨架和能力说明 | 输入值必须保留；失败不等于无结果 |
| 查询更新 | 文档S03有旧结果稳定/更新中 | 缺同页面的明确代表稿；不把首次文件加载冒充每键网络请求 |
| 精确/相关 | 列表标签清楚，不假纠错 | 可接受；原型四词样例不替代现有词典算法验收 |
| 无结果 | 有appelp提示与清空 | 可接受作为没有纠错的例子；有筛选时还需清筛选，不只清输入 |
| 字典失败/部分可用 | 有重试、改查场景词 | 方向可接受；输入范围必须一致；补S14「场景词先用」与S13历史词条暂缺 |
| 生词/到期筛选空 | 文档S08有，原型仅toast | 需代表状态；现有到期筛选入口不应被丢失 |
| 详情/长义项 | 桌面双栏已有，手机源码有单页逻辑 | 需手机详情/长释义截图；不能以状态名「长释义」代替完整可读证据 |
| 加入/失败/已加入 | 有三种按钮/告警视觉 | 去词卡不应固定跳另一个泛化2/8队列；用当前生词/明确“查看我的生词”或构造当前词的示例自测 |
| 发音/来源 | 通用词无全库内置发音，例句缺失有说明 | 边界清楚；实际可用系统朗读仍由设备能力决定，别全面禁掉已有Web路径 |
| 返回 | 详情仅列表scroll，来源链未成立 | L2-04必须修；三种系统返回的真实设备验证仍为实现阶段 |

保留两范围时，「场景词初始浏览」和「通用查词空查询」行为不同：场景范围允许浏览已有条目；通用范围先输入再查。必须在原型/规范对齐。场景查询沿原过滤，不假设已获得通用rank排序。范围切换保持query；去“办公场景词”时明确是否清query以浏览场景，不要继承上一查词把办公列表变成某个词的四条结果。

## 本机、云库、模考边界判定

已认可：资料库三个区「学习资料/本机题包/私人云库」清楚；本机目录明确考试记录仅设备、192MiB容量、已有考试记录题包不可移除；原生云库转系统浏览器；不假装原生身份或云考试记录；模考退出继续计时可见。

需补的代表状态和入口：

- 云题包上传中断/待取消、下载校验失败、下载JSON与下载到本机两个动作；容量32份/2GiB/单份96MiB在管理上下文可定位。
- 本机题包无记录可移除、已有记录不能移除；云删除明确只删云端文件，本机题包/成绩保留。不要把两处删除合成一个危险按钮。
- 本机活动模考的继续卡与已交卷记录入口；预检返回题包；保存失败保持计时可见，交卷确认显示漏答和不可修改范围。
- 模考结果原始答对、Part分布与完整题包格式绑定。演示分母不作为真实统计，但一个标「现行题型」的代表稿也不应画与该格式不符的Part量；可直接使用合成但合乎当前format的分布。

这些都已有真实能力或边界，补稿是保留主要功能，不是新增功能扩张。
