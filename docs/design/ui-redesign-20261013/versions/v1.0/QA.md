## 尚未验证

没有验生产提交/同步/题包上传下载、整份字典排序和性能、真实录音/权限、自然两小时模考、物理手机、Native Back、实体中文IME、软键盘、大字/200%/文本间距、系统读屏、完整主题×页面×状态矩阵。fixture的成功/失败按钮不能作为这些能力的通过证据。

原型只演示屏内来源返回与列表返回；其history.replaceState不是正式应用路由。浏览器系统后退、Android/iOS（非支持目标）或Harmony返回不能直接照搬原型。正式实现使用共享React UI控制器及既有Harmony返回桥。

读取异常不得当空数据覆盖；保存成功才关闭会话；学习key/记录ID、题包与原截止保持。架构线的合成风险不是用户真实数据损失证据，本轮没有修复/迁移存储。
