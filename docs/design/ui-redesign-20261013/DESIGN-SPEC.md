## 1. 范围、目标与现状问题

### 1.1 目标

1. 第一屏回答“今天先学什么”和“回到哪里”，区分到期词卡、错题复练、薄弱 Part 新题与新词；每个队列独立进入，不假造一段串联会话。
2. 五个主要栏目共用导航、层级、组件和状态；完整练习、查词、模考、口语、备份和账号功能可发现且可返回。
3. 查词成为直接可达的独立工具，解决查询、结果阅读、释义展开、加入生词和返回的连续体验。
4. 默认两套主题脱离游戏；游戏两套保留气质，但学习内容同样安静、稳定、可读。
5. 克制地通过排版、对齐、间距、密度和状态细节体现品质。主任务区不使用大插画、连续飘动、厚重毛玻璃和多层渐变。

### 1.2 当前界面需要解决的具体问题

| 当前问题 | 对学习的影响 | 本轮改动方向 |
|---|---|---|
| 大栏目场景、摘要、卡片和多入口同时竞争 | 第一屏难辨下一步；不同栏目看起来近似 | 页面标题压缩到一行层级；任务优先，背景静态 |
| “今日旅程/训练之境/成长足迹”等文案与图片导航依赖较高 | 新用户须解释才能知道操作 | 一级栏目使用“今日/练习/复习/进度/资料”；原功能以明确次级标题保留 |
| 查词位于词库内部，场景词/通用词典/筛选/词卡混在一屏 | 查一个词需要先理解整个词库 | 所有普通页顶部查词入口；独立搜索页；学习词库作为资料入口和复习入口 |
| 详情弹窗承载长释义和来源 | 手机阅读局促，返回容易失去列表语境 | 桌面并列详情；手机全屏详情；恢复查询、筛选与滚动 |
| 主题与栏目场景、动态效果耦合 | 默认主题仍有游戏意象；输入区被装饰影响 | 同一布局四套 tokens；仅游戏主题轻量边缘纹样；题面无图 |
| 常规题组与模考恢复能力没有清晰区分 | “继续”可能被误解为恢复未提交题组 | 页面文案明确保存范围；仅真实可恢复模考提供“继续模考” |
| 正确率和学习自评容易混读 | 词卡自评可能被误当听读成绩 | 进度页分开首次/复练/词卡；未标定练习不换算正式分数 |

### 1.3 本轮保留与非目标

保留今日计划、5 分钟最低版、听读七个 Part、错题与到期题、提交解析、逐句回听和听写、五类口语练习/录音/自评、完整模考导入/预检/恢复/判分、场景词/通用查词/生词/词卡、成长记录、材料筛选/打卡、主题素材来源、目标设置、同步反馈、各类备份与安装指引。

不新增 AI 自动评分、纠错词典、翻译接口、OCR、原生账号同步、短信登录、云考试记录、学力预测、社交排行、付费计划或新的学习算法。`QuestionMark / ResourceTask / restoreBackup` 虽有模型/API，但当前 `StudyApp` 没有消费成已交付界面；本轮不新增错因标记、计划任务编辑或学习 JSON 恢复页面。既有关闭的手机号入口继续保持真实前置门禁。此稿不改变题库、媒体、来源许可、题包格式或当前 192 MiB 本机题库上限。

## 2. 信息架构与导航

```text
今日                 练习                  复习                进度               资料
├ 当前主队列         ├ 听读 Part 1–7       ├ 到期听读题        ├ 近 7 天          ├ 学习材料
├ 5 分钟最低版       ├ 完整模考            ├ 错题再练          ├ 首次/复练        ├ 场景词与生词
├ 待继续模考         │ ├ 本机题包/记录     ├ 到期词卡          ├ Part 分析        ├ 个人题包库
└ 口语（可展开）     │ ├ 导入/预检/开考    └ 自选复习          ├ 卡点手记         ├ 主题素材来源
                     │ └ 私人云题包                           └ 周复盘导出       └ 记录与备份
                     └ 口语专项

所有普通页：查词 → 查询/结果 → 词条详情 → 加入生词 → 返回原页
所有普通页：设置 → 目标/考期/预算/时区、主题、动效、同步/备份、平台说明
专注页：听读作答、词卡、口语计时/录音、完整模考 → 明确返回/退出 → 原入口
```

桌面使用宽 224 px 的静态侧栏：品牌、五项主导航；底部“设置与数据”一项。1440 px 代表稿内容容器 max 1200 px（含左右各40 px padding），等价可用正文 max 1120 px，居中；收窄时采用弹性边距。侧栏不贴一整幅游戏图，不变成独立仪表盘。每个普通页顶部直接提供“查词”，按钮含图标和文本，命中区至少44 px。

手机保留五项底栏“今日 / 练习 / 复习 / 进度 / 资料”，图标 20–22 px，文字 11–12 px，点击区高度至少 48 px，底栏整体高 64 px 加安全区。顶部有页面标题、直接查词、设置入口。正文底部预留底栏和安全区，最后一行及按钮不能被遮挡。底栏不增加第六项，查词不深藏到资料菜单。

查词页在手机隐藏底栏；手机词条详情隐藏范围、查询框、筛选等工具，采用完整阅读面并提供“返回结果”，结果页提供“返回来源页”。常规练习、词卡、口语录音与模考是专注会话，**所有宽度都隐藏全局 sidebar、全局 topbar/查词/设置及底栏**，只保留当前会话上下文返回/退出，不允许桌面导航绕过保存guard。题后相关词查看使用会话内受控返回链，不借全局导航丢失原解析。返回遵循上一层，系统返回与屏内返回一致是实施要求，尚未通过真实系统Back验收。固定操作条只用于需要持续作答的场景；普通列表自然滚动。

## 4. 今日与学习闭环

### 4.1 首页信息层级

页面顶部只放“今日”与简短日期，旁边查词。正文首块为“今天先完成这一小步”，**主CTA只启动它所描述的当前队列**。最终样稿使用“先复习8个词 · 约5分钟 / 开始词卡自测”，下方“接下来”分列“3题复练 · 约3分钟”“Part5新题 · 约10分钟”“新词 · 约7分钟”；合成预算25分钟是方案示意，不是对用户真实队列的计算承诺。不能写成“复习8词并复练3题”却只启动词卡，也不为这句文案新增串联会话。

现有到期和真实Part记录决定具体对象；样稿时间与数量进入生产时须来自已有模型或明确预估依据，不能杜撰薄弱Part或未有算法支持的份量。次项采用编号、任务名、真实/有依据的预计时长与次操作，不再各自放等权彩色主按钮。无到期项显示“今天没有到期项”，主CTA移至真实可用听读计划；首次无记录时显示“尚无首次记录”和“开始5分钟听读”，不展示40%正确率、首答次数、启动历史或待办徽标等历史数字。没有记录与真实0%分开。

右侧/下方仅放今日已学分钟、真实目标与计划说明。考期与预算来自可编辑配置。完整模考活动存在时，在今日主块上方或紧邻主任务显示轻量状态条“有一场模考进行中 · 计时继续”，提供“继续模考”；它不替换所有今日任务，也不暗示退出会暂停。

口语保留但默认折叠，标题为“口语专项”；不与当前听读考期主流程争主 CTA。已记录录音仍能从进度回听。

### 4.2 常规练习流程与退出

```text
今日建议 / 练习 Part / 错题 → 题组 → 选择 → 提交 → 保存结果 → 解析
                                                          ├ 下一题
                                                          ├ 查题内词 → 详情 → 返回解析
                                                          └ 返回目录 / 完成摘要 → 复习安排
```

当前常规练习提交后保存题目记录，**没有持久题组游标**。本轮界面不能承诺关闭 App 后恢复当前未提交题或继续原题组位置。进入/返回当前页面可以保留内存中选择，跨重启以现有真实能力为准。

退出前若有未提交选择，确认文案为“这题还没提交。已提交记录会保留，重新开始会打开题组。”按钮“继续这题 / 返回目录”。无未提交选择时直接返回；已提交记录已保存则小字“已提交答案已保存在本机”，账号同步是否完成另列状态。保存失败时保持题目、答案和操作上下文，给出“重试保存”；不得显示成功或以离开替代错误处理。

**答案、学习时间与账号同步分别表达**：当前每题提交保存答案，学习时间在完组后的现有打卡动作另记。退出中途不能笼统显示“学习进度与时间已保存”；完成摘要显示真实答对/题量、样题不换算正式分数，提供“记录时间与收获 / 先休息一下”，取消打卡不撤销已保存答案。打卡复用现有字段：实际学习分钟必填整数1–240（现有经过时间可预填、用户可修改）、负荷“轻/刚好/重”默认刚好、可选手记≤1000字。只有既有`addCheckin`成功才显示“时间与收获已记录”；方法名只写在内部规格，产品文案不出现实现名。不新增心情、错因或自动计时保存接口。“已提交答案N题 / 本组尚未打卡 / 等待账号同步”可同时出现，账号同步仅在有真实账号通路时显示。

“继续哪里”只用于真实活动模考、可明确定位的已存在学习入口或当前内存会话。一般听读 CTA 使用“开始下一组”，不给出伪造“恢复到第 N 题”。如未来需要持久题组游标，另立数据设计与验收，不偷偷附加到纯界面重构。

### 4.3 复习与词卡

复习页先显示到期听读题和到期词卡，再显示错题/自选。两种复习入口都有明确对象和数量。到期0但仍有错题时显示“今天没有到期复习，错题仍然保留”，保留“3道错题可巩固”这类基于真实记录的复练入口；不能将到期为空解释为整个错题库为空。错题来源进入作答后标“题目复练 · 首答记录保留”，不当成“新题首答”。空队列是完成状态，提供次级“复练错题”“查看生词”，不能人为制造待办。首次/复练并存，提前自测不提高间隔，词卡自评不计入听读正确率。

词卡先展示词头和发音，点击后翻出释义，随后出现“还没记住 / 记住了”。翻面只是原位置展开，不旋转3D；按钮布局在长释义下仍可滚动抵达。每次评价完成写入后再移至下一张，失败停在已翻当前卡，显示“待保存：记住了/还没记住”，保留具体反馈、不给完成数加1，提供“重试这次反馈”。默认重试同一待反馈；若允许改选，要清楚说明取代当前未保存反馈而非另评价一张，保持既有card/事件ID规则。退出说明此前已评价保留、当前待反馈未计完成。结束显示本组已评价的真实数量；当前词卡组不承诺跨重启恢复游标。

### 4.4 模考、口语与素材

模考目录、预检、开考、答题卡、阅读阶段交卷、结果和原题解析需要连续可审阅路径。退出确认说明“计时不会暂停”；沿现有`leave`先保存interrupted中断状态，成功后离开。失败默认留在当前页，原计时可见，显示“退出记录未能保存 / 重试保存”；同时保留已有明确风险动作“未保存仍退出”，它须二次明确告知未保存范围，不能直接dismiss或写安全退出，也不能把现有风险离开彻底封死。恢复使用原截止，不能重新给45/75分钟。计时、播放、交卷状态不随主题切换重置，错误提示不能遮住计时。

题包来源、旧制/现行、首次/复测明确标记；练习正确率不换算正式 TOEIC 分数。云库只同步题包，不显示“成绩已同步”。有记录的本机题包不能移除，容量不足时提示现有上限与按需导入，不建议清理学习数据。

模考结果“查看错题解析”保留原模考上下文，不进入普通原创新题首答。v1.0曾用题包A第103题短句稿；v1.1已扩原图、单篇与多材料、旧制和缺解析模板，不把103固定为全模考唯一复盘页。原题包ID/版本/题号/首次复测/原截止保持。旧制预检显示原format/声明时长；保存失败显示“本题未保存”，不泛称自动保存已成功。

口语不是“保存成功才可回放”。当前`onstop`先得到Blob、objectURL并进入done，随后异步persist；**整理完成后、保存中或保存失败仍可回听当前Blob**。保存失败保留`last(meta, Blob)`、可见播放器、重试保存、下载录音与明确放弃风险；“再说一次”“记录收获”才受saved门禁。保留练习发生时间与文件ID，参考表达/自评不增加AI自动评分。五类任务、准备/失败/回听/退出的具体布局见4.5，不以这一段摘要替代完整口语稿。

### 4.5 口语完整页面与状态（F01）

口语为本轮完整重设计范围。目录从练习页“口语专项”进入，五类使用相同可比较列表：任务名、实际练习标题、准备/作答时限、材料类型、打开动作。不以单个朗读卡替代全部任务；不增加AI成绩、正式考试估分或额外题组服务。

|---|---|---|
| SP01目录 | 五个类型行和真实准备/作答标签；列表上方说明原创练习、自评 | 返回练习目录；不改任务ID |
| SP02就绪·图或长文 | 任务标题、材料、英文提示、45/30等实际时限；“开始准备” | 可返回目录；未录音不增加录音记录 |
| SP03权限申请/拒绝/不支持 | 等待许可保持任务；拒绝显示设备/浏览器设置指引与“重试”；不支持显示现有Web/更新系统路径 | 不模拟实际授权成功；许可响应失效须停掉新取得的track |
| SP04准备 | 明确“准备”剩余秒；“准备好了，现在录音”“取消准备”；材料保持可读 | 返回取消准备、释放stream并回ready；不写作暂停后无条件继续原倒计时 |
| SP05录音中 | 明确红色/图标“正在录音”、剩余时间、单主动作“结束录音”；材料不移动 | 返回先stop，不能直接`navigate(practice)`丢Blob；按现有时限自动停止 |
| SP06后台/中断 | “已结束录音，回来后可回听”；准备后台则“准备已取消，请重新开始” | 按现有foreground生命周期；保存中的clip不能被第二次背景事件撤销 |
| SP07整理录音 | “正在整理录音，请稍候”，稳定任务/发生时间上下文；短状态占位 | Blob尚未产生时不能显示可用播放器；不允许直接退出 |
| SP08done保存中 | Blob可用后立即出现播放器、实际时长；“正在保存，仍可先回听” | saved=false；再录/记录收获禁用并给原因；返回留页等待 |
| SP09保存失败 | 错误面“录音暂未保存”；播放器；“重试保存”“下载录音”“放弃并离开” | 保留`last(meta, Blob)`/objectURL；下载仅发起文件保留，不能宣称正常DB保存成功 |
| SP10保存成功·回听 | 播放器、发生时间/时长、真实本机保存/等待同步状态；自评清单与参考表达展开；“再说一次”“记录收获” | 参考表达仅现有字段；自评不成为AI分数；再录创建新的录音ID，先前成功记录ID不重建/覆盖 |
| SP11自评/参考表达 | checkbox条目自然多行；参考英文表达与现有朗读动作，播放器属于本人录音 | 不将未记录自评说成服务端审阅；“记录收获”接已有打卡模板 |
| SP12准备时返回 | “取消准备”完成后回任务ready；第二次正常返回可到目录 | 释放track/取消未完成permission generation，保留当前任务 |
| SP13录音时返回 | 停止录音→整理→尝试保存的受控状态；取消离开/继续回听 | 不绕guard；先保留已录内容，不将“离开”理解为继续后台无限录 |
| SP14保存失败时退出确认 | 明确“这段录音尚未保存”；回听/重试/下载可见；“留在这里”“放弃这段并离开” | 只有显式放弃后离开；不删除已成功保存的历史录音；下载不等同DB保存 |
| SP15录音历史 | 进度页“我的录音”列表：标题、配置时区发生日期、时长、本机/已确认同步状态；点击回放 | 采用既有recordingUrl：优先本机Blob，仅有owner且uploaded确认才读已有云副本 |
| SP16历史回放失败 | 单条错误“找不到这段本机录音，也没有已确认的云端副本”；重读/返回历史 | 不把失败解释为无录音或删除元数据；无下载能力的历史不画假下载按钮 |

保存中的回听与失败时下载是现有能力，必须体现在实际补稿，不能只在文档宣称。v1.1口语模块负责人补桌面/手机SP02（至少一项图片或长材料）、SP04/05、SP08/09、SP10/11、SP14；SP15/16由进度/资料模块提供共享播放器模板和入口定位。失败场景不得调用真实麦克风或生产存储来“造”证据。

### 4.6 模考、媒体与交卷全路径（F02）

```text
本机题包/记录 → 原format预检 → 人耳试听确认 → 开考并产生原截止
   ↓续考                         ↓
活动考试 → 完整LC音轨+图题/题页 → RC长/多材料阅读 → 手机/桌面答题卡
                                                  ├ 继续作答
                                                  └ 提交整卷（仅RC）→ 确认漏答/未保存 → 提交中
                                                                         ├ 成功 / 到时交卷 → 七Part结果 → 原题解析
                                                                         └ 失败 → 原计时/保存范围/重试
```

| 格式 | 预检/结果显示 | Part 1–7分母 | 保留要求 |
|---|---|---|---|
| 当前格式（format省略） | “现行题型” | 6 / 25 / 39 / 30 / 30 / 16 / 54 | 使用既有profile；不能因缺字段猜成旧制 |
| `legacy-2006` | “2006版旧题型·补充练习” | 10 / 30 / 30 / 30 / 40 / 12 / 48 | 旧制单独判分与标记，不混作现行考前基线 |

LC声明范围为40–50分钟，**按整秒声明，不要求整分钟**：`listeningDurationMs`是安全整数且可被1000整除，如45:59；未声明使用45分钟，RC固定75分钟。预检显示原声明与媒体实际时长，不向整分钟取整，差异/不足门禁沿既有行为。开考后不开放自由seek、倍速或暂停考试；中断恢复按已经过的考试时间对齐原音轨，不能从暂停点另给剩余时间。只有预检/练习回听可使用现有试听操作，不把自由播放器控制移植到正式LC。

预检尚未开始本次考试，身份使用未来措辞“将记录为首次完整模考 / 将记录为第1次复测”，不写“已记录首次/复测”或已经产生结果。开考成功后才进入本次持久考试身份；原有历史次数/题包身份仍可显示。冻结模块的`miniIdentity`在examsetup使用“将记录为…”语义；这是作者源码响应，不是外部终审关闭。

|---|---|---|
| EX01本机目录/活动记录 | 顶部活动模考、题包行、已交卷记录；每行题包ID/版本、现行/旧制、本机容量；继续/预检/查看结果 | 不删除有考试记录的题包；云库≠考试同步 |

冻结考试模块共50个page/state条目：examcatalog 3、practice-media 12、examreview 5、exam 19、examsetup 6、examresult 5。包含photo-submitted、long-submitted与listening-save-error（LC已选答案未保存，原轨/计时继续）；定位见覆盖表。此计数不等于50项都经独立交互/像素复验。

### 4.7 资料步骤、打开与打卡闭环（F04）

```text
资料分类/筛选列表 → 展开材料详情 → 阅读步骤与访问条件 → 原站打开材料
```

## 5. 查词流程与完整状态

### 5.1 能力边界

当前通用词典包含 84,979 条词形与短语，支持英文/中文、规范化文本后的词头精确匹配、前缀、词内、释义/词形文本包含查询。多关键词须全部包含；排序为词头精确 → 词头前缀 → 词头包含 → 释义等其他命中，再按词头长度/字母排序。场景词沿用现有搜索与分类，不改变 ID 或复习事件。

方案里的“相关匹配”专指已有前缀/包含/释义命中，**不是拼写纠错、编辑距离、语义搜索或联网补词**。页面不会显示“你是不是想搜……”或凭空纠正错词。通用词典不是托业词表；场景词 807 个，另有 55 个题内表达，共 862 个学习条目。两类来源与许可保留。

当前收藏状态是“加入生词本”，并不证明词已学会。统一保留这个真实动作名称；详情中显示“已加入生词本”，复习日期只有既有记录提供时才显示。新增场景词没有现有例句则不生成例句占位；通用词条没有内置发音时提示设备朗读或离线缺失边界。

### 5.2 默认路径

```text
普通页面“查词” → 独立查词初始页 → 输入/提交 → 数据就绪 → 结果列表
                                                     ├ 精确词条 → 详情
                                                     ├ 相关匹配 → 详情
                                                     ├ 无结果 → 换关键词/清筛选
                                                     └ 加载失败 → 原查询下重试

详情 → 加入生词本（成功/失败） → 返回结果（查询、范围、筛选、已显示数量、滚动均保留）
结果 → 返回来源页（恢复来源页面的位置与已有状态）
```

查词页面顶部：返回来源页、标题“查词”、查询框和清空。范围为“英汉查词 / 托业场景词”；场景选择只在场景范围出现。学习筛选为“全部 / 我的生词 / 到期”，采用可换行分段按钮，不藏在难发现的图标里。不加入查询历史持久化接口；需要初始示例时只用固定提示“可输入英文词头或中文释义”，不伪造最近搜索。

手机结果状态压缩重复大标题、长说明及装饰眉题，保留可见查询标签、范围/筛选与来源返回；结果列表不被四段解释推到下半屏。至少390无评审工具条真实视口能比较前两条结果，320仍见第一条及下一条起点。通过去重复内容与收紧区块间距达成，不将正文/必要信息缩到13px以下、不减少44px命中区。练习目录的完整模考设在标题附近的清楚次入口，七Part行使用紧凑对齐，不把模考只放长列表末端。

### 5.4 桌面与手机细节

视口宽度≥1200 px时使用结果/详情双栏；1440代表稿结果列约320 px，详情使用剩余空间，列宽稳定、阅读正文约65–75英文字符。冻结为**双栏整页纵向滚动**，与本轮原型一致；不增加两列独立滚动容器或额外滚动状态。未选择时右栏显示“选择词条查看完整释义”；选择后高亮列表行，不跳页面顶端、不重排列宽。<1200 px回到单列列表→详情；<1024 px再采用手机完整阅读面，隐藏详情上方查询/范围/筛选工具。手机每屏一个主滚动区。

手机使用列表→全屏详情。列表导航快照至少保存：`query / mode / category / filter / visibleCount / scrollY / selectedWordId / originPage / originScroll`，仅为UI状态，不进入学习数据库。详情返回先恢复已显示条目，再恢复结果页整体滚动，焦点回原词条按钮；返回来源恢复原页面位置。原型已演示内部返回source/results、query与结果scroll，其他条件快照及浏览器后退/Harmony原生返回的一致性是生产实施契约，不声称当前原型全量支持。账号切换清空用户特定详情/会话与筛选状态，避免上一账号生词泄露。

F12修正：进入详情的滚动/工具隐藏断点与CSS一致，完整详情面≤1023px不能仍只在≤700px滚至标题。补701–1023px（至少840px）长列表→长词详情→返回原行/scroll取样；不以源中存在断点差异直接宣称设备故障已复现。F11修正：Ctrl/Cmd+K同时排除常规作答、模考、口语与`reviewcard`，生产快捷键与所有入口经统一退出控制，隐藏导航不足以证明guard。

手机搜索框字体至少 16 px；输入使用正常文本键盘与搜索动作，不强制关闭自动组合输入。IME 组合期间不自动提交、失焦、清空、重排到光标以外；`event.isComposing` 与 composition 生命周期都要验证。用户点击提交/条目时再按正常行为收起软键盘，不因每次更新结果强制 blur。软键盘展开时固定底部栏不覆盖结果或输入，查词专注页无五项底栏；详情与操作区使用视口安全区，测试 ArkWeb 的键盘收缩行为。英文超长词头允许换行，中文释义自然换行；不使用把整段中文撑宽的 `nowrap`。

## 9. 动效策略

状态变化 120–180 ms：颜色、边界、透明度。面板进入 180–220 ms，位移不超过 8 px；无需每页进场。翻卡为内容展开/淡入，120–160 ms，不使用翻转或弹簧晃动。主题切换可用 180 ms 色彩过渡，考试/音频/输入状态不重建。

不新增常驻粒子、水光、雨雪、花瓣、场景镜头或进度数字滚动。既有“轻动效”偏好迁移为当前克制状态动效，尊重明确关闭与系统 `prefers-reduced-motion`。减少动态时取消位移与动画、直接切状态。加载保留静态骨架与状态文字，不要求动画才能理解。后台、离屏及专注学习时无装饰循环。

## 10. 无障碍与跨端可用性

实施目标为 WCAG 2.2 AA 的可核查项：正文/标签对比至少 4.5:1，大字至少 3:1（[W3C 1.4.3](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)）；识别控件/状态所必需的视觉信息与相邻色至少 3:1，停用及用户代理原生外观等例外另判（[W3C 1.4.11](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)）。装饰分割线不冒充必须满足该值的功能边界。

WCAG 2.2 AA 指针目标最低为 24×24 CSS px 或满足规定例外；本项目选择更舒适的至少 44×44 px、移动主操作 48 px（[W3C 2.5.8](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)）。禁用态之外所有可操作元素有清晰 focus；AA 要求焦点组件不能被作者内容完全遮挡，本项目进一步以不遮挡操作为目标（[W3C 2.4.11](https://www.w3.org/WAI/WCAG22/Understanding/focus-not-obscured-minimum.html)）。上述不等于本应用已符合全部 WCAG。

键盘可到达主导航、查词、范围、筛选、结果、详情、收藏、媒体、答案、提交、返回与设置；顺序沿视觉层级。列表行用真实 button/link；不依赖 hover。查词结果总数/加载状态使用 polite live region；错误使用 alert，但不在每个击键播报全部结果。原生返回先关最内层详情/确认，再返回来源，不跳过尚未提交确认。

页面有 landmarks 与顺序正确的标题。正确/错误使用文字和图标。英语题文标注语言，播放器有明确名称；图表附可读数值。题目图片/原页有现有可提供的说明与放大入口，保留不能替代扫描文本的限制；不能宣称纯图片试卷已完整屏幕阅读可用。

200% 浏览器缩放与手机系统大字不截断按钮、底栏、词头或释义；320 px 宽度正文无横向页面滚动。另实际测试用户覆盖行高 1.5 倍、段距 2 倍、字距 0.12em、词距 0.16em 后没有内容/功能丢失；这些是适应性测试值，不是所有正文默认排版（[W3C 1.4.12](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html)）。折叠屏展开/收起时保留答案、录音、查询与滚动，依据实际可用宽度重新排版。验证中文输入法、软键盘、长中文释义、超长英语短语、底部安全区、屏幕阅读和键盘，实际设备证据单独记录。

## 11. 性能与工程边界

默认主题不加载游戏大图或字体文件。游戏主题仅必要小纹样，可用原创内联矢量/小资源；总量单独预算，建议每主题装饰新增资源 ≤ 20 KiB 压缩后。字体采用系统栈。页面大媒体沿用现有按需加载，不把题包音频、扫描题页或私人材料打入公开包。

词典按需加载且复用解析/索引；查询期间输入不阻塞，先保持最新文本，再更新结果。仍使用已有查询算法，优先限制一次渲染条目：初始 24 条，再显式“再显示 24 个”，回返还原已显示条数。不为了视觉引入无限滚动或未经验证的虚拟列表；若性能测量证明有必要，单独核验滚动与无障碍。

不为主题变化重新解析 84,979 条词典、清空查询、销毁音频或重建考试。收藏/事件状态按现有一次分组策略处理；不在每个词条渲染时扫描全部事件。搜索结果更新不整页 reload，缩短任务不能改变学习算法或日志。

后续测量目标：在约定设备和同等数据集上，输入到可见反馈通常 ≤ 100 ms；首次词典读取单独展示，不承诺把大文件读取时间伪装为搜索延迟；字典就绪后新查询到首批结果 p95 目标 ≤ 150 ms，输入过程中不连续出现 >50 ms 的主线程任务。当前原文件约 15.6 MB，`useDeferredValue` 不会把解析和索引构建移出主线程；若实测长任务超标，再考虑 Worker/分块，并复核返回、读屏和旧数据兼容。新设计部分 CLS 目标 ≤ 0.05。首屏体积不显著超过当前基线，默认首屏不携带词典与主题图。上述采纳独立工程审查的待验收目标，不是本轮已测数值。

### 12.3 保留的架构风险与另线整改

以下是本轮架构合成审查提出的保留风险，不能用界面草案表示已修复：读取失败不得被当作“空库”后立即覆盖或迁移；口语退出须服从录音保存保护；事务Promise只靠abort结算的竞态和R2/D1同ID风险由既有架构工作线另行整改。此阶段不扩大为存储重写、认证变更或数据清理。

### 14.5 最终候选取舍

| 议题 | 取舍 | 理由与后果 |
|---|---|---|
| 查词放第六个底栏，还是保留五栏 | 保留五栏，普通页顶部直达查词 | 不挤压五个现有主要栏目；移动一跳可用 |
| 手机弹窗详情，还是全屏详情 | 全屏详情；桌面双栏 | 长释义阅读、键盘和返回语境更清楚；增加 UI 状态恢复工作 |
| 四主题是否各自换布局 | 共用布局与状态，仅 tokens/小装饰变化 | 减少记忆成本与四套回归分叉；游戏主题靠气质而非场景占屏 |
| 游戏大插画与高级感 | 不使用主区巨图与常驻动效 | 题目/输入区稳定；默认主题彻底去游戏；装饰只在边缘 |
| “继续学习”要否暗示常规会话恢复 | 仅真实可恢复模考使用继续；常规用开始下一组 | 尊重已有能力，不引入新持久化算法 |
| “近似结果”如何命名 | “相关匹配”，解释为前缀/包含/释义 | 避免暗示纠错或语义服务；拼错无结果保留真实边界 |
| 搜索是否加无限滚动/历史/AI解释 | 初始 24 条+显示更多；无新增服务 | 保持真实接口与性能可控；回返恢复已显示数量 |
| 口语在今日的权重 | 保留可展开入口，低于听读任务 | 符合当前听读考期，又不删除现有录音/专项功能 |
| 默认主题自动跟随系统 | 本轮四套手动主题，不加第五项 | 避免扩范围；仍尊重系统减少动态与大字 |
