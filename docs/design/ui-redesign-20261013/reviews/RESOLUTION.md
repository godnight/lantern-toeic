# 评审分歧与具体修订

日期：2026-10-13。版本：v1.0 内部评审修订稿；待父会话独立终审。

## 取舍

| 分歧 | 决策与理由 |
|---|---|
| 学习产品更倾向把查词放底栏、进度移至首页 | 保留五个原学习领域，普通页顶部44px查词一击可达；查词专注页隐藏底栏并提供来源返回。保留已有导航记忆，独立评审接受此取舍；父复审可继续判断发现性 |
| 合并场景词/通用词典为统一搜索 | 暂留两范围，显式来源与学习边界；精确、前缀、词内、释义延续现有排序，不引入假纠错服务 |
| 默认蓝色、跟随系统日夜，还是绿色四套手动 | 日间墨绿/暖白、夜间炭灰/薄荷；四套手动一选一。系统减少动态优先。跟随日夜不是本轮新增设置 |
| 顶部大图与IP识别度 | 默认日夜完全无游戏；游戏仅48px页边纹样/预览，题面不插画，清晰学习层级优先。游戏艺术仍可在父视觉审阅中定稿 |
| 桌面列表/详情分别滚动 | 本稿冻结整页纵向滚动的双栏，手机每屏一个主滚动区；避免未演示的滚动复杂度 |
| 保留光边/blur/氛围循环 | 不使用全屏blur和常驻粒子。120–180ms交互反馈，主题短切换；减少动态时直接完成 |
