## F03：非颜色识别的具体规范

### 1. 同一个 48px 规格

| 项目 | 项目规范 |
|---|---|
| 外盒 | 所有普通页与设置预览均为 **48×48 CSS px**，不伸展、不压缩；删去 90×70、52px 和≤350px隐藏差异 |
| 内图 | 40×40px，有 4px 内边距；主形占内图约 75–90%，不要缩成中央 20px 的灰色线团 |
| 笔画 | 主线 2.5px；必要次线 2px；少量细节最低 1.75px。48px下最多两级笔画，不用大量1px纹路 |
| 色与透明度 | `opacity:1`；使用骨白/象牙或明确的正文级颜色。主题符号与其背面目标对比≥4.5:1，最终由实际 token 核验；不用 .22/.55 隐淡身份 |
| 静态与语义 | 静态原创 SVG；装饰不加入交互命中区，不遮挡功能；`aria-hidden`，主题名称仍是可读文本；不能用符号替代页面标题 |
| 普通页限制 | 只在页标题边缘和主题选择预览出现；内容区不重复。听读题面、词义、搜索输入、录音主体和模考保持纯净 |
| 默认主题 | 日间/夜间普通页没有这两套游戏符号；设置中的四主题选择可以预览两游戏主题，这不等于默认正文继承游戏艺术 |

### 2. 两套不同的形态语言

**空洞主题：对称、纵向、包围式节奏。** 主结构为完整门拱，顶部圆拱与垂直石柱，内部一层较小洞门形成稳定的“外拱—内洞”节奏。中央可使用原创骨白切面/面具负形：不规则的两孔与下收轮廓，保持明确的洞穴空白。建议两侧各一处短石段，最多 2–3 层结构；轮廓对称，中心稳定，留白集中在门洞。不要直接描摹官方角色头、角或标志，不加入针/丝/钟线。

**丝歌主题：不对称、斜向、穿行式节奏。** 以一根可识别的斜针为主轴，针眼可为 4×6px 负形；一条连续丝线穿过针眼，形成一个宽松环，另以钟口/钟沿的弧形作为边缘收束。针需具有尖端和针眼，不能只是无目的斜线；钟与丝线不用形成与空洞相似的对称门拱。建议主轴倾斜约 20–30°，线环向一侧外展，最多 1 个大环与 1 处弧边，不堆交叉细线。

两者在统一单色下应仍区别为“稳定洞门/骨白负形”与“斜针穿线/钟弧”。颜色只强化身份。采用相同外盒、笔画尺度和视觉重量，不能空洞满盒而丝歌像极淡小签名。

### 3. 390px 与 320px 普通页位置

| 宽度 | 布局与尺寸 |
|---|---|
| 390px | 主内容左右20px，可用350px。普通页标题区可采用 `minmax(0,1fr) 48px`，gap12px；图形对齐标题区上边或文字块中线。标题28/36px，眉题13/20px，说明14/22px。长标题允许自然两行，不降低字号 |
| 320px | 主内容左右16px，可用288px。将48px符号放在独立**眉题行右端**，眉题在左；主标题下一行占全部288px。符号不在标题文字列中挤出第四行，也不隐去。眉题行高48px，行后8px；说明与标题间8px |
| 条件切换 | 仅当实际可用宽足以容纳正文列时并排。不能只以设备名称判断，也不能以低宽媒体规则隐藏游戏身份 |
| 其他普通页 | 今日、练习、复习、进度、资料、外观均采用同一标题组件；不要每页自行调透明度或新增背景插画 |

320px独立眉题行是为了给符号确定的可读位置，同时保留标题宽度。它不适用于查词/作答等专注页；这些页继续去除游戏图形，所以不会给搜索头部额外增加48px。

## F10：主题选择须是真实内容与状态

现有预览只有无文字横条和色块，能比较明暗，不能验证必要信息、选中、正确/错误。新稿应使用同内容、真实 DOM 组件的预览，不把截图缩到难读，也不以假骨架代表最终界面。

### 主题选择布局

- 桌面保持2×2四卡；内容区每卡最小宽约300px，卡间16px，外部卡边与网格对齐。
- **320/390px建议单列四卡**，每卡用完整可用宽288/350px。这是外观设置的低频选择页，可以自然滚动；不要在138/169px的两列中把真实任务文字缩成9px。若主代理坚持手机两列，必须提供不用缩字、内容未挤压的实际稿再判断。
- 每卡内边距16px，标题行48px：主题名称16–18px/24px，48px原创符号靠右。日间/夜间可用纯文本描述，保留同高标题行，不引入游戏装饰。
- 选中主题用2px可见边框、勾图标及“正在使用”文字；不能只靠色彩或边框。未选中卡也显示名称与明暗描述。
- 内层真实任务面与外层选择卡之间只有一次16px间隔，不再嵌套多层阴影、玻璃或装饰面。

### 所有四卡必须展示同一组内容

| 预览内容 | 字体/状态 |
|---|---|
| 同一任务标题，如“短句填空 · Part 5” | 16–18px/24px、600；四卡完全同文案 |
| 同一简短英文题干或中文说明 | 14px/22px，不替换为横线；允许自然换行 |
| 同一已选择答案行 | 最低44px高，14px正文；字母、边框/侧标和“已选择”文字共同表达 |
| 正确状态样例 | 13px/20px必要文字、勾与“正确答案”；保持文字可读，不能按disabled整体降透明 |
| 错误/保存失败样例 | 13px/20px，明确错误图标/标题、独立error surface；丝歌错误与主题主色仍靠形态/文字区分 |
| 一枚主操作 | 最低44px高，14px/20px，不用3px骨架线替代按钮 |

这些可以作为卡片内“组件状态示例”表达，不应伪装为同一道题同时正确又错误的真实作答。可把正确与保存失败并列为明确命名的状态样本，四卡采用同一种状态安排。预览仍不接真实题包、成绩或存储。

### 必要小字

保存状态、来源/许可、题型/首次复测、精确/相关匹配的含义属于必要信息，**冻结最低13px/20px**；正文16px/26px。装饰性眉题和导航短标签可以按已定规范用12px，但不得把核心保存/来源信息降为装饰标签。英文字头和题目正文不能缩字来解决卡宽问题。

## F09：手机查询与目录密度

### 查询首屏

当前手机结果稿的第一条约在522px（含约70px评审栏），去掉评审栏仍约452px，确实需要压缩。最优先删除的是重复的“词汇 / 查词 / 找到词义，再决定要不要学”三段，而非降低结果字号。

建议专注页顶部一行56px提供“返回今日/返回练习解析”与明确“查词”标题；不再重复一枚查词目的地按钮。正文从查询工具开始：

| 部件 | 320/390建议 |
|---|---|
| 正文起始间距 | 16px |
| 范围切换 | 44px高，14px/22px；“托业场景词 / 英汉查词”保留清楚边界 |
| 范围到输入 | 12px |
| 查询输入 | 52px高；输入16–18px，可读标签与清空44px目标 |
| 输入到筛选 | 12px |
| 状态筛选 | 44px目标，可折行；全部/我的生词/到期依已有范围保留，不新增筛选功能 |
| 结果计数与词典范围 | 13px/20px，移到结果面顶部或筛选下单独一行；不要硬挤在320px三筛选右边 |
| 结果行 | 76–88px：词头18/24px，短释与词性13–14/20px，左右16px；命中区至少44px |

隐藏评审工具条后的取样目标：390px第一结果起点尽量≤300px；320px因筛选折行可≤330px。第一屏能比较至少两条真实结果，而不仅看到一个大选中块。这是项目设计目标，不是浏览器已测结果。范围、结果和详情的真实状态恢复仍归产品/工程契约。

### 练习目录

普通页标题后16px给一条清楚次入口“完整听读模考 →”，有现有状态才显示“继续”；口语与场景词入口仍独立。让模考在七Part列表之前可发现，避免用户翻完列表后才知道有整卷。

Part行建议72–80px（原稿近90px），左右16px、上下12–16px；左Part列56px不换行，中间标题16px/24px+状态13px/20px，右箭头44px命中。行之间分隔线，不加图像缩略图。320px较长中文标题自然换行，必要时行高随内容增加，不固定裁切、不缩16px正文。新增空间来自减少无信息的上下留白。
