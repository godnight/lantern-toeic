## 可以保留的方向与分歧回应

- **暖白/墨绿与炭灰/薄荷**：与首轮提出的中性蓝不同，但当前默认稿自洽且与空洞的冷墨蓝区分，接受这个项目取舍。不要求为了接近 iPhone 再换成蓝色。
- **标题与密度**：首轮建议 32/28，规格曾写 28/24，实际原型 CSS 为桌面 32。当前桌面首页标题和手机标题可读，信息次序清楚；具体数值应在规范与实现间冻结一致。不要把“更大标题”当成下一轮主要工作。
- **五栏 + 固定查词**：手机普通页上方“查词”有文字，五个底栏短标签易理解；支持保留五栏，前提是查词专注页有明确返回。桌面多一个查词侧栏入口不构成手机第六栏问题。
- **列表替代大量卡片**：练习、搜索、资料、复习弱项列表已能比较条目。首页一枚主任务块与次级任务行形成明确次序；无需重新增加图像封面。
- **游戏表达量**：实际练习/复习手机稿中的边缘纹样克制，作答题面纯色可以保留。当前两个符号更接近抽象主题记号，用户是否认为辨识度足够仍属父会话设计取舍，不宜用巨幅场景补救。
- **日夜系统策略**：接受本轮四套手动主题、不新增第五套或系统策略。系统减少动态和大字响应仍应保留。
- **长词阅读**：`mobile-search-long-night.jpg` 中超长词头有自然断行，长正文与来源完整展开；加入生词按钮位于正文后，没有被固定条压住。样例刻意重复“3.”只是压力内容，不应当作真实词条质量，也不能替代实际长词/多义词样例。
