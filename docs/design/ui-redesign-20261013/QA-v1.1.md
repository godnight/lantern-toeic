## 范围与证据

运行的是独立静态原型 `prototype/`，只绑定 `127.0.0.1:41873`。所有作答、保存返回、计时、回放与下载均为标明的合成示例，不访问账号、私人题包、麦克风、学习存储或云端。普通页面仍沿用 v1.0 信息架构，v1.1 补齐遗漏流程及修正一致性。

1. 四个补稿模块及基础脚本使用 Node 语法检查；模块作者另核查 fixture 路由和状态渲染。那些检查是静态设计检查，不等于生产功能测试。
2. 根任务使用受支持浏览器 UI 操作亲验下面三条连续流程、键盘防跳转与中间宽度详情；DOM 与新拍稿的布局记录保存在 [layout-evidence-v1.1.json](layout-evidence-v1.1.json)。截图目录另包含补稿阶段已经拍摄的状态，不把其作者检查混称为根任务全量交互实测。
3. 冻结补稿后的新浏览器标签，在这些交互和新截图结束时读取 error/warn，返回空列表。编辑过程的旧标签曾记录未完成模块的语法错误，不纳入最终冻结稿“零错误”结论。

## 保留的实现验收项

读屏与键盘完整焦点循环、系统字体放大 / 减少动态 / 高对比、Portal 与提前返回模考的全域 token、真实低端设备与离线字典、LC 播放恢复和 RC 期限、Blob 保存失败、备份导入验证和 Native Back 顺序，都必须在审定后的实现中验证。静态稿不宣称 WCAG 整体合规。字体采用现有系统字体，无新增联网字体 / 依赖；装饰为轻量原创 SVG，禁止学习题面背景图和循环动效。

设备验证分三层：浏览器验证布局与合成状态；DevEco / HarmonyOS 7 模拟器验证真实壳、返回与存储集成；最终 Pura X Max 真机验证内外屏切换、录音权限与音频、后台恢复、升级后数据保留。父会话只读确认 DevEco 26.0.0.821 / SDK API 26 已安装，LanternOffline7 模拟器已停止且无已连接设备，本阶段没有启动或安装。浏览器 `nativeMode` 不能记为模拟器或真机通过。
