# v0.3.3 · 个人题包库与旧题型练习

网页版新增按账号隔离的个人题包库：完整 JSON 题包上传一次后可在其他设备下载。云端使用 D1 目录和 R2 文件，最多 32 份 / 2 GiB，每份不超过 96 MiB；上传、下载均核对 SHA-256。下载到本机后继续使用离线计时、首次与复测、答案判分和完整备份。

鸿蒙版提供浏览器题包库入口：在系统浏览器登录网页版、下载 JSON，再回 App 导入。无需随每份题包重新安装 App。尚未接入百度网盘 API，也没有原生账号认证或考试记录云同步。

新增明确标注的 2006 版旧题型（10/30/30/30/40/12/48）；无 format 字段的原有题包仍按现行题型验证，字节与指纹保持。旧题型用于补充训练，不替代现行考试基线。IndexedDB 升至版本 3，旧版 App 不应降级打开新库。

本机容量保持 192 MiB，新增显式移除未作答题包；凡已有进行中、首次或复测记录的题包都禁止移除，保护历史和备份自洽。私人下载材料与答案保留在私人题包中，不编入公开源码或 HAP，不将文件夹的“真题”字样视为真实性认证。

版本 0.3.3 / 升级号 20009。测试、构建和设备结果见 [执行报告](../testing/TEST_EXECUTION_v0.3.3.md)。
