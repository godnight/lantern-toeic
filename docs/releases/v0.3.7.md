# v0.3.7 个人练习版

面向当前私人网页和鸿蒙离线练习，鸿蒙版本码 20040。保留已有学习记录、题包和 Sites 账号归属，不重置数据。听读备考继续使用练习、词库、模考和资料入口；连续训练支持作答后听写、逐句回听及草稿恢复。

- 鸿蒙新录音改为按实际采样保存 PCM/WAV，避免原 MediaRecorder 生成极短文件却显示数秒的问题；采集不完整会提示，不能按墙钟伪造录音时长。
- 录音支持 0.75、1、1.25、1.5 倍回听。旧录音格式继续可读。
- 上传重试核对实际音频和练习时间；并发或不同内容不能覆盖已保存录音。
- 修复无效日历日期和备份导出反馈，限制同步请求大小以保护接口。

本版保留原私人访问范围。新账号服务仍在独立验证分支，不会自动替换现有个人账号；真实手机号登录未接通。没有新增可公开分发的 ETS 真题素材。

验收范围与设备限制见 [测试记录](../testing/PRACTICE-RELEASE-20261018.md)。模拟器合成信号测试不能代替真机麦克风和人耳验收；issue #47 不因自动化通过自动关闭。升级后不得直接安装不支持 v2 会话的旧 r3 版本回滚。
