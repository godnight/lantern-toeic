# v0.1.0 · 听读备考离线测试基线

本次按用户要求，将已完成 Pura X Max 真机验证的词库与录音功能固化为测试基线。原开发版标签 v0.2.x 保留，源码没有回退；鸿蒙 versionCode 递增至 20005，后续功能版从 v0.3.0 继续。

- 295 个词汇入口，双语搜索、生词本、词卡复习及独立 JSON 备份；鸿蒙内置离线发音。
- 冷启动与离线保存、原生文件导出/重复导入、后台停止录音、重启后回听已有真机证据。
- 修复录音列表跨时区日期错误；经历失败用例、修复和同一录音真机回归。
- 加入设备自动化 runner、带校验值的 Web/HAP/源码构建交付、草稿附件核验后再发布的流程。
- 固定项目经理职责和版本计划，以 2026-12-20 听读考试为当前重点。

详细验收及未测项见 [测试报告](https://github.com/godnight/lantern-toeic/blob/v0.1.0/docs/testing/TEST_EXECUTION_v0.1.0.md)。附件 `QA.md` 为报告快照；`build-info.json` 记录源码、构建运行和附件哈希，下载后用 `SHA256SUMS.txt` 校验。

公开 HAP 为未签名调试包，需自行开发签名才能安装；不包含个人设备 Profile。已在用户手机验收的私有签名包保持本地交付，它与本次重新编号的公开构建不是相同字节。Web 构建需要现有 Sites 运行时及 D1/R2 配置；发布 GitHub Release 不代表线上 Site 已部署。

新设备自动化 runner 首次 live 验收仍待模拟器协议确认；其夹具测试不替代真机。手机号登录、原生云同步、商店发行和完整真题模考尚未包含。本次不提供正式托业分数预测。
