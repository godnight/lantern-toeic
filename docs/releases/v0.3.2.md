# v0.3.2 · 场景扩词与英汉查词

托业场景词从 240 个扩至 807 个，保留 55 个题内表达。新增词按办公、人事、会议、财务、销售、物流、出差、酒店餐饮、技术、设施、健康和社区分组，提供项目自编的中文场景义及单词合成发音。

新增独立的英汉查词入口，按需加载中文维基词典英语数据。支持中英文与词形搜索、优先显示精确词头、音标和有来源的词源参考，查到的词可加入生词本、翻卡复习及原有 JSON 备份。原词条的 ID、释义与学习记录保持；通用词典不自动进入每日学习任务。

通用词典不是托业词表，也未覆盖全部常见词；全库没有人工审校。部分词有音标、词形或词源，其余留空。场景词的内置发音可以在鸿蒙断网播放；通用查词结果未逐词附带离线音频。新增场景词的例句朗读、跟读录音和记忆联想将在后续补充，本版不声称已完成。
