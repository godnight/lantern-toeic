# v0.2.2 · 独立美术库与可靠同步

源码预览版，不包含已签名、真机验收的鸿蒙 HAP。

- 建立 `art/` 独立美术库：空洞骑士、丝之歌参考分别归档，19条来源已确认入口、1条待核验候选；第三方图片不随应用打包。
- 6幅可交付原创主题图，新增2幅1672×941环境图；记录提示词、真实尺寸、来源和SHA-256。美术库版本为0.1.0，两套插画主题为1.1.0。
- 网页/APP共享主题素材浏览、分类、原作入口和主题切换；在主题选择框点击“浏览主题素材”。
- 逐条隔离同步失败，临时错误最多自动尝试3次，退避和次数跨刷新保存；可单独手动重试，原始记录保留。
- 缺失音频有可见提示，后续有效录音仍可上传；云端确认后修复本机元数据；同步期间新增记录自动续跑。
- 处理多标签迟到失败、账号变更、响应体超时和过长Retry-After；无效JSON/录音表单返回明确输入错误。
- 浏览器与审查发现的提交兼容、复习题组、局部损坏恢复、缺失录音、未保存重录和迟到设置回退均已修复并补回归。
- 新增鸿蒙工具链缺项检查。当前仓库有Hvigor启动脚本，但本工作环境没有可用的完整HarmonyOS SDK、OHPM或HDC；检查工具存在不等于编译通过。

测试设计与执行：[39个场景设计](../testing/TEST_DESIGN.md)、[本轮执行报告](../testing/TEST_EXECUTION_2026-09-08.md)，附截图、命令日志及未测/阻塞项。

本地验证：33项实际源码行为回归、类型、68题/5类口语/22官方资源结构、美术目录/哈希与Web构建通过；移动端共享构建和GitHub各端CI见本发布提交对应的Actions。

旧学习记录与首次作答模型不变；新增的同步问题状态按账号存在本机独立键内，不删除待同步原文或音频。原生端仍为本机记录，原生云同步、完整备份、稳定签名及真机验收待完成。

该源码发布不自动部署私有Site，也不代表v0.3计划/错因功能已经实现。v0.3继续按Issues #8–#10推进；网站、SDK编译、安装包和真机证据分别记录。
