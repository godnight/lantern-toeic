# 微光托业 v0.2.4

发布日期：2026-09-12。

## 本版内容

- 手机安装入口增加HarmonyOS、Android和iPhone的浏览器/PWA步骤。
- Web/PWA明确使用私有Site的ChatGPT身份，同一账号下通过D1/R2同步学习记录与录音。
- 原生容器明确为本机保存，提供安全打开在线同步版的入口。
- 应用、mobile、Android、iOS和Harmony版本统一至0.2.4，并增加手机入口回归测试。

## 安全与交付边界

本版没有配置短信服务商或手机号认证后端，因此不收集手机号，也不提供无法验证的短信验证码界面。原生手机号登录需在确定供应商、隐私规则、滥用防护与账号合并策略后单独实现。

HarmonyOS目录仍是可导入DevEco的工程与同步网页资源。本次环境缺OHPM、HDC和HarmonyOS SDK，未生成或签名HAP，也没有真机录音、覆盖升级或安装验收。源码检查、构建、浏览器及线上结果见 [v0.2.4测试执行报告](../testing/TEST_EXECUTION_v0.2.4.md)。
