# 微光托业 v0.2.4

发布日期：2026-09-13。

## 本版内容

- 手机安装入口聚焦HarmonyOS浏览器/PWA步骤。
- Web/PWA明确使用私有Site的ChatGPT身份，同一账号下通过D1/R2同步学习记录与录音。
- 鸿蒙原生容器明确为本机保存，提供安全打开在线同步版的入口。
- Android/iOS源码冻结在v0.2.3，停止自动PR/main构建；共享网页构建包与Harmony版本更新至0.2.4。
- 增加鸿蒙入口回归测试与两份RFC，分别记录平台收敛和手机号认证架构。

## 安全与交付边界

本版推荐使用华为AGC认证，但没有收到AGC应用配置、短信模板/配额、令牌验证后端或公开登录入口授权，因此不收集手机号，也不提供无法验证的短信验证码界面。完整前置和验收见 [RFC 0002](../rfcs/0002-phone-auth-and-online-data.md)。

HarmonyOS目录仍是可导入DevEco的工程与同步网页资源。本次环境缺OHPM、HDC和HarmonyOS SDK，未生成或签名HAP，也没有真机录音、覆盖升级或安装验收。源码检查、构建、浏览器及线上结果见 [v0.2.4测试执行报告](../testing/TEST_EXECUTION_v0.2.4.md)。
