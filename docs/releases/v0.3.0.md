# v0.3.0 · 本机完整听读模考

此前只有零散原创练习和官方资源链接，不能在应用内完成整卷。现在可导入多套个人完整 200 题 JSON 题包，完成音频/图片预检后按 45 分钟听力、75 分钟阅读作答，交卷查看正确题数、漏答、Part 表现和答案解析。

后台、退出和重启不暂停计时；恢复按原截止时间校准，媒体中断留有标记。答题事务成功才提示保存，首次与复测分开，完整备份包含题文、答案和音频。题包只保存在本机，Web 按登录账号隔离，鸿蒙使用应用本机范围。

真实浏览器回归纳入 Core 与发布门禁，覆盖导入、冷开、阶段切换、提交、复测、备份与窄屏。详情见 [测试报告](https://github.com/godnight/lantern-toeic/blob/v0.3.0/docs/testing/TEST_EXECUTION_v0.3.0.md) 与 [题包格式](https://github.com/godnight/lantern-toeic/blob/v0.3.0/docs/EXAM_IMPORT.md)。

没有预装官方完整真题；已下载的 60 题官方原样样题仅私人交付，不是整卷。当前导入不含 PDF OCR。没有依据明确的本卷换算表时，不推算正式托业分数。私有材料和测试用合成题包都不进入 Web/HAP 发布内容。

公开 HAP 为未签名调试包，版本 0.3.0、升级号 20006；本地开发签名包另行交付，未安装新版本到真机。浏览器受控快进不是两小时续航或实际听音验证；鸿蒙新模考、大备份落盘、其他设备仍待验。手机号登录与原生云同步未包含。

附件 `QA.md`、`build-info.json`、`package-verification.json` 和 `SHA256SUMS.txt` 记录本次实际构建。Sites 发布与 GitHub Release 分别核验，保持旧版标签与附件不可覆盖。
