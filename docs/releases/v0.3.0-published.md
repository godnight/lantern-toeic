1. 用户醒来后先试原网页，用原账号登录；如仍不能打开，记录浏览器、错误与网络情况再定位，保持现有私有权限。
2. 手机连接并授权测试后覆盖安装本地签名包，保留旧学习、词库和录音；验证新版 ArkWeb 导入、备份落盘、后台恢复及真实听音。两小时连续运行与大文件仍待验。
3. 模拟器协议已获本人明确同意并完成接受，既有镜像已启动；不用再次确认协议或下载镜像。真实截止、独立短流程及剩余边界见[自动化报告](../testing/HARMONY_MOCK_AUTOMATION_2026-10-11.md)，当前操作以[最新交接](../CODEX_HANDOFF.md)为准。
