# v0.3.5 连续训练本地候选

状态：开发候选，未发布；鸿蒙版本码 20015。基于已验 r3，复用原题组与学习事实。

作答后可继续同材料的第一句听写和逐句回听，保存步骤、草稿、核对关系和最近音轨定位。已答题可返回深练；查看旧题不回拨评分游标，听写、跳过和回听不新增 Attempt/Checkin。只有原有手动用时确认才记学习时间。

保存分为待保存、保存中、已确认、失败、未知和冲突。未知重试沿用原操作；失败保留本页草稿，退出前须保存或明确选择放弃未保存内容。恢复不自动播放。Web 系统朗读仅保存句子定位，从句首重播；鸿蒙现有内置音轨支持暂停续播和明确从头播放，实际秒级误差仍须独立平台验收。

会话采用 ARCH-CT-v0.2 的 session v2 内嵌 training。旧 v1 原始数据与历史回执保留，仅明确训练编辑时升级。**旧 r3 不支持读取或导出 v2 会话，不能把安装旧 r3 当成安全回滚。** 回退必须使用兼容 v1/v2 的 reader/导出版本并禁写，保留备份与原库；不得删除 training 或重新创建学习事实。

本候选不含真实手机号、公开多用户服务或新的公共素材许可。未核公开许可的音轨没有复制进 Web 包。新首学/账号说明的后续本地改动另存候选外，未混入本训练批次。没有 push、合入、Sites 部署、Release 或手机安装。

开发证据与未验边界见 [开发验证](../testing/CONTINUOUS-TRAINING-DEVELOPMENT.md)。开发通过不代替独立 QA、用户视觉确认或发布授权。
