# v0.3.1 · 完整听力音轨与旧题包升级

部分完整卷的音频超过 45 分钟，旧版本会在最后一组还未播完时切换阅读。本版允许题包声明整轨时长：例如 45:52.521 的原音频可声明 45:53，听力结束后仍保留完整 75 分钟阅读。未声明的旧题包保持原 45 分钟规则及指纹。

开始前实际读取媒体时长；声明不符或旧题包音频超出默认截止时，阻止开考并说明原因。后台和冷启动继续使用同一绝对截止，不能通过重新播放延长考试。旧本机数据库原地升级；升级后旧版 App 无法打开模考库，降级前请保留完整备份并使用新版读取，不要卸载清数据。

模型、存储、原页打包器及实际浏览器回归见 [测试报告](https://github.com/godnight/lantern-toeic/blob/v0.3.1/docs/testing/TEST_EXECUTION_v0.3.1.md)。合成静音音轨只用于验证播放与计时，未替代真人听音或连续两小时硬件测试。

公开 HAP 为未签名调试包，版本 0.3.1、升级号 20007。私人完整题包另行交付，不嵌入公开源码、Web 或 HAP；正式托业分数没有相应换算表时仍只报告正确题数和各 Part 表现。手机号登录和原生云同步未包含。

附件包含 HAP、Web 构建包、源码、QA.md、构建信息、包体验证报告及 SHA256 校验值。Sites 部署与 GitHub 预发布独立记录。
