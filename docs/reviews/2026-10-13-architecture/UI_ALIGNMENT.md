# 与全页面重设计对齐的工程约束

本次架构审查与并行「重设计微光托业界面」方案保持独立目录。以下是已核对的实现边界；新视觉方案可以调整布局/导航，不应隐含扩展云同步或迁移真实学习记录。

| 设计对象 | 实际契约 | 对方案/后续实现的要求 |
|---|---|---|
| 四套主题 | 现持久ID `hollow/silk/paper/crystal`出现在profile、备份、API枚举和CSS。现全部IP相关，不满足新无IP日/夜 | 先定明确旧值兼容表；可沿用ID语义映射或做版本化alias迁移。不可仅删枚举/更名，也不可静默重置profile |
| 无IP日/夜 | 配色与 `mapScenes.views[nav]`独立；导航/任务/休憩缩略图仍含IP | ThemeDefinition须同时定义完整语义token和scene/nav/task/rest素材策略，默认两套覆盖全部IP入口；用户本轮目标优先旧美术决定 |
| 根级主题 | 模考 `.mock-shell`提前返回；Dialog Portal在body；现有root和atlas映射值不完全一致 | 根级token覆盖首页、词典、练习、模考、口语、书库、设置和弹层；检验默认、选中、禁用、警告、错误、键盘focus和reduced motion |
| 主题保存 | `useStudy.saveTheme` + 原子theme API；完整saveProfile仍兼容旧队列 | 切主题用theme-only，不把默认学习目标提交为整profile；首云GET、跨标签、刷新、离线重连均保留用户目标 |
| 查词入口 | 懒加载整份84,979词典；打开词库即开始读取；核心学习词仍独立可用 | 展示加载/失败/重试及源类型；查询无结果和尚未加载不同；不要让词典加载失败锁死场景词 |
| 搜索结果/详情 | 807场景词+55题内表达有学习ID；通用库补义项/词形/词源；精确/前缀优先；词根与词形不同 | 场景释义优先，保留来源许可；通用条目不宣传托业考纲/官方真题词表；收藏/自测才产生记录 |
| 发音 | 鸿蒙仅1,015段精确文本匹配的离线音频；通用词典未全覆盖；Web系统朗读 | 准确展示不可用/播放/暂停/错误；不要假设每个查词结果都能离线发音或有例句音频 |
| 进度和“同步” | StudyData、VocabularyEvent、ExamAttempt、云题包四套存储 | 分域标识同步/本机/待处理；练习首答率、词卡自评、模考Part结果不可混成同一成绩或共同“已同步” |
| 原生云库 | 系统浏览器登录下载JSON后回App导入，owner=null原生未登录 | 保留下载/导入步骤与账号说明；不可承诺App内直连百度网盘/后台考试记录同步 |
| 考试导航 | 活动考试固定截止、串行revision写入、离开保存中断；不因停音频/后台暂停计时 | 确认退出/交卷、保存失败阻止误离开、图片区Back优先、未本人试听不开考；主题/页面切换不重建考试ID |
| Back/录音 | 同步boolean priority栈：录音100、模考90、图片50、词典30、壳0 | 新弹窗/页面保留回退与保存顺序；退出录音必须处理未保存Blob；不能通用close直接卸载所有子组件 |
| 备份恢复 | 学习JSON不含录音文件且恢复UI未接入；词卡有独立备份；模考完整备份含包与历史且已有恢复UI | 明示每个备份覆盖范围。不要把模型/hook待接入界面画成现成能力；若拟增加入口，须列为单独实现项及验收范围 |
| 错因/资源计划 | QuestionMark/ResourceTask模型/API/hook存在但StudyApp未用；资料打卡当前靠note内`[资源:id]` | 新设计先表达现有复习选择和真实打卡；新增标记/计划编辑需清楚分阶段，不能顺带将note变更为迁移所有旧记录 |
| 布局与性能 | 搜索全库扫描/排序；模考媒体在主线程分配；原生共享包与Web不同宿主 | 320/390/840/1440基线之外补折叠/键盘/ArkWeb；主题动效在学习、弹窗、后台、离屏及系统减弱动态时停；性能目标先测量再定 |
