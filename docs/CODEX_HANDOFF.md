# 开发接续

1. 读取 [当前状态](PROJECT_STATUS.md) 和 [分级发布规则](RELEASE_POLICY.md)，按当前任务选择相关文件。需要职责分工时再读 [团队](TEAM.md)。
2. 当前已交付源码为 a4b78796456094ae840770b48c5a9bd5554d7306，0.4.5 / 20059。PR54 尚未合并，不能只检出旧 main 再覆盖这些工作。新任务从明确的已验收集成基线建立短分支/PR，保留已有用户改动。
3. 明确负责的目录和唯一写入者。先判断是文档、局部 UI、模块功能还是大版本/高风险，再选检查。没有变动的模块继承既有结论。
4. 只在依赖缺失或锁文件变化时安装。scripts/install-ci.sh 用于安装；scripts/codex-setup.sh 还会执行完整类型、内容、素材和学习行为检查，按需调用，不默认在每轮接续运行。
5. 运行本次所需验证，构建实际要交付的目标。涉及账号或登录链路时同步执行[账号相关验证](RELEASE_POLICY.md#账号相关验证)，模拟器与真机结果分别记录。最终 HAP 一次签名和官方验签，原位升级；不重签 SDK/工具、不重复扫描同一产物。
6. 更新一份简短结果，说明版本、检查、交付状态及真实剩余问题。不要再把每轮快照复制到 README、状态、交接和各角色文件四份。

## 当前边界

- 平台：Web/PWA、HarmonyOS；mobile 目录是共享离线网页构建入口，不自行恢复 Android/iOS。
- 学习：首答/复练、服务端评分、用户隔离、SRS、原始练习时间和旧记录仍需保持。
- 服务：复用既有 Sites/D1/R2；手机号供应商未配置时保持关闭，不用固定码或前端状态代替登录。
- 素材：保留蓝湖及已确认场景，修改内容要核对应来源与实际显示，不重审未变全库。
- 录音：偶发杂音仍开放，用户已暂停定位。
- 发布：遵循已有授权，默认不打 tag；开发、QA、发布各用同一份结果，不增加形式化批准层。
