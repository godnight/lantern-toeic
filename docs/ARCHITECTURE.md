# 架构与数据

## 共享产品

`app/study-app.tsx`和`app/learn/`为React界面；`lib/study-model.ts`为纯学习逻辑；`content/`为版本化原创练习。Web由Vinext渲染；`mobile/`是鸿蒙共享网页的Vite入口，构建后由`harmony/scripts/sync-web.mjs`打入ArkWeb本地资源。Android/iOS工程和Capacitor依赖已删除。

## Web身份与存储

服务端通过产品身份服务读取和校验账号身份；`/api/study`与`/api/recordings`拒绝无身份请求，变更还校验请求来源与客户端期望用户。客户端不自行创建可信身份。

服务端数据模型包含 D1 的 profile、attempt、checkin、recording 元数据及 question_marks、resource_tasks；R2 可保存用户隔离路径下的录音。数据迁移位于 drizzle 目录，逻辑绑定为 DB 和 BUCKET。这些实现能力不代表当前入口已启用跨端同步。

本机按用户分区保存学习数据，录音 Blob 保存在 IndexedDB。同步实现支持本机快照、不可变操作和 ack，并在启用远端学习时处理联网或重新聚焦后的同步；当前 Web 入口显式关闭远端学习，原生入口也未启用，因此不能将这些实现能力描述为当前已开放的自动跨端同步。服务端在处理作答时重新计算正确性，并检查期望用户；账号切换会使旧请求失效。

录音保留实际createdAt，上传时间另记。个人JSON导出不包含音频文件，当前版本尚无完整音频备份/恢复、删除账号或迁移UI。

## 数据版本与可修改实体

StudyData 使用 schemaVersion=2；旧快照通过纯函数补字段，既有记录 ID、首答、分钟和 note 保留。标记与资源任务按 revision、取消优先、mutationId、规范化内容的顺序合并，同一规则用于本机操作日志、备份恢复和数据库原子 upsert。新表以用户及实体 ID 为复合主键，取消状态作为记录保留。远端未来版本会写入账号分区的最低版本要求，阻止刷新及其他标签页继续用旧代码上传。

JSON 导出包含新实体；代码恢复接口幂等合并，录音仅恢复元数据，不信任导入的 uploaded 标记。资源任务的 minutes 不计入实际学习时长，实际时长仍来自 checkins；带 checkinId 的任务等待父记录确认后同步。标记/任务编辑、完整今日计划及恢复界面分别后续实现，细节见 [RFC 0003](rfcs/0003-study-data-v2.md)。

## 离线边界

Web Service Worker只缓存公开静态资源，不缓存私有HTML、API、用户数据或官方站点音频。已打开的练习可继续记本机记录；冷启动离线显示说明页。Native 自带静态页面与练习；通过账号核对后，学习区使用当前账号的本机分区，旧游客记录另有恢复入口。

原生端已有账号入口和华为账号登录能力，具体可用方式由账号服务及设备能力决定。当前原生和 Web 入口均未启用学习记录跨端同步；同一账号登录不代表学习记录自动跨设备共享。

## 学习规则

首次和复练事件永久并存，周正确率基于最早事件。复习优先级：最近仍错或到期→未做→未到期；成功间隔递进为1/3/7/14/30天，提前连续重复不升等级，错误重置。当前不是FSRS或统计预测模型，错因标签、遗忘模型和教师调节仍在后续计划。

完整听读模考支持按账号本机分区导入和保存符合格式的 200 题题包、媒体、作答及考试记录；未预装完整真题，需使用者导入有权个人使用的完整题包。模拟考试并不等同于正式监考或考试认证。

日任务由预算和Part表现生成少量题。周复盘是本地规则总结，未调用外部AI服务，也不向外部模型发送录音。任何后续AI评分需显式产品说明并区分练习反馈与正式评分。
