# RFC 0005：本机完整听读模考

状态：实现中，2026-10-11。用户本次只参加 12 月 20 日听读考试，先完成导入与模考功能；完整官方材料取得独立跟踪。

沿用 Web/鸿蒙共享 React，新增严格完整 200 题 JSON 题包，提供默认 45+75 分钟固定截止时间、断点恢复、交卷、Part 分析与答案复盘。完整听力音轨的可选时长扩展、旧包兼容和存储升级见 [RFC 0006](0006-complete-listening-duration.md)，阅读仍为 75 分钟。个人题包放独立 IndexedDB，按已确认 owner 隔离；不混入旧学习正确率、时间、D1/R2 或词库备份。Web 身份缺失时不回退匿名空间；鸿蒙本机使用稳定设备范围。

题包与历史不可原地覆写，修改须新版本；同试卷 ID 跨版本延续首次/复测序号。并发写入检查 revision，备份恢复原子合并且拒绝覆写后续答题。时钟按绝对时间推进，后台和媒体失败都不延长；时间回拨保留已观察高水位并标记结果。

导入来源是用户声明，不自动获得官方认证；完整真题、官方练习、原创内容明确区分。参考分只允许该套材料有出处的区间，不伪造 990 分换算。公开发布不包含私人题包；合成 fixture 只测试结构与功能。

暂不实现 PDF OCR、任意网页采题、跨账号迁移、原生云同步和历史删除。完整格式及限制见 [题包说明](../EXAM_IMPORT.md)。验收须覆盖保存失败、账号切换、超时恢复、媒体失败和窄屏；两小时真实材料、低内存大包及鸿蒙下载落盘未验项必须保留。
