# RFC 0004：场景词库与独立学习记录

2026-09-19。状态：实施。用户要求给现有学习应用增加托业词库。

## 内容与界面

首版 240 个常见职场和生活场景词，12 类各 20 个。选词、中文释义、搭配和双语例句原创整理，含 AI 辅助；不是 ETS 官方词表、完整考纲或经词频统计的排名。沿用 LICENSE-CONTENT.md 的 CC BY 4.0。补充已有题内表达，保留一词多题、多义解释与原题入口。

训练之境和学习书库均可进入，支持中英文搜索、场景过滤、生词标记、每组最多 20 张词卡、自评复习。先揭示答案才能评分，不将词卡自评写入听读答题、打卡时长或估分。记不住时 10 分钟后再见；按时记住使用 1/3/7/14/30 天间隔，提前反复记住不升间隔。

## 持久化

词库独立于 StudyData v2，避免现有迁移、备份、API 丢弃未知集合。复用网页版已验证的账号边界，但不扩展尚未接通的鸿蒙手机号认证。

- 独立 `vocabulary_events` D1 表，以 `(user_id,event_id)` 为主键；追加事件、相同事件幂等，冲突返回错误，未知旧词 ID 保留用于将来词库升级。
- `/api/vocabulary` 使用服务端身份、来源校验、owner 请求头和私有 no-store 响应，参数化 SQL。迁移仅新增表，不改既有学习表。
- 本机 journal 按设备或 owner 分区，每次写入一个新键，避免多标签覆盖整份快照。联网网页版拉取合并、上传缺失事件；鸿蒙离线版仅本机存储。
- 标记按 revision 排序，同 revision 取消优先，再以事件 ID 稳定决胜；review 按时间及 ID 重放。UI 仅在本地写入成功后前进，未来版本或损坏记录不覆盖。备份导入先验证，单次写入新增事件，重复导入无副作用。
- 词库 JSON 备份单独导出和合并，页面明确不包含在旧听读/录音备份中；鸿蒙仅新增一个允许的下载文件名。

## 发音

复用 SpeechPlayer。浏览器使用设备英语语音；鸿蒙将精确词文本合成 MP3，与已有题目音频一起校验文本与文件 SHA-256。标注合成语音，不冒充真人或官方音频。

## 验证边界

内容数量/完整性、双语搜索、重复导入、取消标记、复习间隔、跨标签并发、owner 隔离、损坏/未来格式/存储失败、API 鉴权与事件冲突；浏览器手机尺寸及鸿蒙模拟器验证实际操作。真机安装、真人听音验收仍需设备配合。
